# 需求

在模型广场列表的 Grok 模型卡片中，像 Seedance 一样使用价格总览表展示真实目录价格。

## 验收标准

- Grok 图片、旧版视频和 Video 1.5 按各自计费维度显示三列表格。
- 图片模型展示输出分辨率、图片输出价和图片输入价。
- Video 1.5 展示输出分辨率、视频输出价和图片输入价。
- 旧版 Video 展示输出分辨率、视频输出价，以及图片/视频两类媒体输入价。
- 每个价格直接显示人民币符号和计费单位。
- Grok 卡片不再显示 `¥1 / 请求` 锚点或 Token 单位。
- 数据来自后端 `molii_grok_pricing`，不得在展示组件硬编码价格。
- 非 Grok 模型和详情弹窗保持现状。
- 提供数据层/组件相关测试、类型检查、格式检查、构建和浏览器验证。

## 限制

- 不修改计费逻辑或后端 API 契约。
- 不调用 antigravity 或 Claude。
- 不 push、合并或创建 PR。
