# Molii Docusaurus 文档站需求

- 审计 Molii Volcengine Imagine API 与 Molii Grok Imagine API 渠道和接口适配缺口，并给出优先级建议。
- 使用 Docusaurus 建设专业产品文档与用户侧 API 接口文档。
- 平台文档仅覆盖普通用户操作，不包含管理员操作。
- 文档站可以与 `new-api` 位于同一 Git 仓库，但必须作为独立应用、独立依赖、独立构建和独立部署。
- 不修改或耦合 New API 的 `web/` 前端，不把文档资产编入 Go 后端二进制。
- 基于真实源码、路由、DTO、模型注册和计费逻辑编写文档，不猜测接口。
- 不公开管理员接口、上游凭据、真实密钥或内部敏感实现。
- 保留当前工作区内用户已有的生成记录计费修改。
- 使用子代理并行完成审计、架构与内容盘点。
- 本地文档开发服务使用 `127.0.0.1:3100`，支持热更新。
- 只生成可自托管的静态构建产物，不添加 Cloudflare Pages、Vercel 或其他第三方云部署配置。
- 使用 Docusaurus 官方默认主题与默认 Infima 样式，不做品牌化视觉重设计，不添加自定义颜色、字体、渐变首页或卡片动效。
- 当前只有一个 Seedance 渠道；第 2 项实现唯一启用渠道约束，不实现多渠道素材亲和。
