# 需求：模型广场手动排序

## 目标

- 取消 `/pricing` 模型卡片默认按发布日期排序。
- 由 `/models/metadata` 中管理员保存的模型顺序控制模型卡片默认顺序。
- 由供应商管理中管理员保存的供应商顺序控制 `/pricing` 供应商筛选项顺序。
- 模型顺序与供应商顺序相互独立，不按供应商强制重组模型卡片。

## 管理端交互

- 模型元数据页提供“修改排序”入口。
- 进入排序模式后显示全部模型，每行最前方启用拖动按钮。
- 排序模式提供保存和取消；搜索、筛选、分页及批量选择不参与排序。
- 供应商管理提供同样的排序模式、保存和取消行为。
- 拖动必须支持指针、触屏及键盘上移/下移。

## 公开展示

- `/pricing` 默认按模型手动顺序展示。
- 访客仍可主动选择名称、价格升序或价格降序。
- 删除“最新发布”排序选项。
- 发布日期字段及依赖发布日期的首页最新模型、详情信息不受影响。

## 数据与安全

- 模型和供应商使用独立持久化排序字段。
- 新建记录追加到末尾。
- 批量排序必须在事务中校验完整 ID 集合并原子更新。
- 并发新增、删除或无效排序请求必须拒绝，不允许部分保存。
- 支持 SQLite、MySQL 和 PostgreSQL；Development PostgreSQL 迁移可重复执行。
- 排序成功后刷新定价缓存和相关前端查询缓存。
