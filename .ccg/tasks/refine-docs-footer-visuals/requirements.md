# 修正文档 Footer 图标字体和尺寸

## 需求

- 厂商列表使用与首页一致的真实 Lobe 品牌图标，不使用字母占位。
- Footer 字体与首页一致，不继承文档正文的 Lora Serif 字体。
- Footer 的字号、图标尺寸、间距和整体比例与首页一致，不能受文档站 12px 根字号缩小。
- 保持 `/docs/` 子路径、移动端响应式、无障碍及现有链接行为不变。

## 验收标准

- 桌面浏览器实际计算的正文链接字号为 14px、栏目标题为 12px、品牌 Logo 高度为 48px、厂商图标为 16px。
- 厂商图标使用品牌图形资源，DOM 中不存在字母占位徽标。
- Footer 使用首页的 Public Sans 字体栈。
- 桌面与移动端无页面级横向溢出，文档完整测试和构建通过。
