# 产品报价及计算器需求

## 目标

在 new-api 超级管理员后台增加“产品报价及计算器”，位于 Task Plugins 与系统设置之间。功能复用 `/api/pricing` 及现有定价逻辑，允许选择模型、按 provider 设置折扣和备注、计算分组倍率、实时预览并导出离线 HTML 报价单。

## 权限与数据边界

- 仅超级管理员可见、可访问；前端路由与后端接口均复用现有权限机制。
- 不修改实际模型价格、分组倍率或其他计费配置。
- 报价数据首版只存浏览器草稿，不增加报价历史数据库。
- 价格来自 `/api/pricing`，provider 对应 vendor，model ID 对应 model_name；必须在实现中以接口结构和现有 pricing 消费逻辑复核。

## 价格与计算

- 保留文本输入/输出、缓存、按次、图片、视频、阶梯和动态价格等维度、币种与单位。
- 动态价格若不能可靠归一化，展示条件或“待确认”，不得填零或伪造单价。
- 明确价格基准、用户分组、币种与获取时间，避免重复套用分组倍率或折扣。
- 折扣用中文“折”：8 折为原价乘 0.8；支持全局值与 provider 覆盖，provider 优先。
- 汇率与折扣计算器按 `分组倍率 = 实际汇率 × 折扣系数 ÷ 系统固定汇率` 计算；例如 6.8 汇率、5 折、固定汇率 7，结果为 0.4857x。
- 不把不同单位的单价合并成总金额；小额价格保留足够有效精度。

## 编辑与预览

- 报价标题、报价人、报价日期（默认当天）。
- 按 provider 分组搜索、模型勾选、整组选择和全选。
- provider 独立折扣覆盖与备注。
- 桌面端左编辑右预览，小屏合理堆叠。
- 预览为商务白纸样式，复用站点品牌信息，按 provider 分区；模型 ID 可复制。
- 完整处理加载、失败重试、空数据、未选模型和无效输入。
- 草稿自动保存在当前浏览器，刷新恢复；刷新价格不清空草稿。

## HTML 导出

- 下载完整独立 `.html`，内嵌 CSS，无需登录、联网或站点资源。
- 预览与导出共用同一报价数据和价格计算规则，导出冻结当前快照。
- 包含模型、全部适用价格维度、provider 备注、报价人、日期与价格获取时间。
- 所有文本安全转义，具备 A4 打印样式和合理分页。
- 文件名包含净化后的标题与日期。
- 无选中模型、加载失败或输入无效时阻止导出并解释原因。

## 验证

- 覆盖折扣优先级、零价格、小额价格、不同维度、动态价格、无效输入、模型选择、备注转义、草稿恢复、导出快照和权限。
- 运行受影响测试、类型检查、lint 和生产构建。
- 检查真实页面与导出 HTML 的视觉效果。
- 不部署生产。
