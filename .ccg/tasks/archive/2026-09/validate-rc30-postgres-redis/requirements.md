# 实施约束

- 只支持并验收 Molii 实际使用的 PostgreSQL 15 与 Redis 7；SQLite/MySQL 不作为发布条件。
- CI 使用隔离服务容器，不读取开发或生产环境秘密。
- 先用失败测试稳定复现 `controller -race` 的异步测试隔离问题，再修复后台任务生命周期。
- 开发环境必须先生成 PostgreSQL 可恢复备份并校验，再执行任何候选版本迁移。
- 不执行 `FLUSHDB`、`FLUSHALL` 或其他清空开发 Redis 的操作；用带命名空间的探针验证连接和 TTL。
- 开发环境迁移验证采用停写、单实例启动、二次启动幂等检查和功能冒烟。
- 任一备份校验、迁移、计费、任务结算或回滚检查失败都阻断合并与推送。
- 最终目标分支为 `develop`；只有全部门禁通过后才合并并推送。
