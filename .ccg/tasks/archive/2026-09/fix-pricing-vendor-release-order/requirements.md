# 修复公开定价页排序

## 预期行为

- `/pricing` 默认推荐顺序首先遵守管理员配置的供应商顺序。
- 同一供应商的模型连续展示，不被其他供应商模型插入。
- 同一供应商内按发布日期从新到旧排序。
- 日期相同或缺失时采用稳定、确定的兜底顺序。
- 用户主动选择名称或价格排序时，继续尊重用户选择。
