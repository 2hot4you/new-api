# Seedance 用户视频生成工作台

## 已确认范围

- 所有登录用户均可访问新的 Seedance 视频生成页面。
- 页面自动读取当前用户在 `/keys` 中已有的可用 API Key；用户明确选择一个 Key，不手动填写密钥，浏览器不得获得完整密钥。
- 支持 Seedance 2.0、2.0 Fast、2.0 Mini、2.5，以及各模型当前支持的全部请求参数。
- 支持首帧/尾帧模式与多模态参考模式，并在界面与服务端阻止不合法混用。
- 支持图片、视频和音频：本地直传 COS、选择当前用户临时素材、填写公网 URL。
- 本地素材上传完成后自动加入请求；提交任务时由服务端生成最新 COS 签名 URL，避免签名过期。
- 复用现有 Seedance relay、渠道路由、计费、任务轮询、结算、退款、视频代理预览和下载链路。
- 结构化展示请求参数、素材数量、任务状态、耗时阶段、用量、费用、错误和视频结果。
- 长期保存完整提示词、生成参数和素材逻辑引用；不长期保存短期 COS 签名 URL。
- 历史记录支持查看和一键复用；过期素材保留记录但要求重新上传。
- 历史任务必须同时覆盖 Molii Volcengine Imagine API 与 ByteDance Seedance 渠道。
- 外部 `/v1/videos` API 契约保持不变。

## 安全约束

- 服务端重新校验 API Key 所有权、状态、有效期、额度、模型限制和分组可用性。
- 用户只能访问自己的素材、请求快照、任务和结果。
- 不向普通用户暴露渠道密钥、完整 API Key 或仅管理员可见的上游诊断信息。
- 防止重复提交；失败任务继续走现有结算/退款队列。
