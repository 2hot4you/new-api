# Seedance 用户视频生成工作台实施计划

## 约束与复用边界

- 复用现有 `/v1/videos` 的渠道选择、参数校验、计费、任务持久化、轮询、结算与结果代理；工作台只增加会话认证适配层。
- 浏览器仅提交用户拥有的令牌 ID，服务端按会话用户重新读取和验证令牌，完整令牌不返回前端。
- 复用 `/api/assets/self` 的 COS 上传、URL 素材、素材库和用户隔离；请求快照只保存逻辑素材引用，不保存短期签名 URL。
- 不新增依赖，不新增数据库表。工作台请求快照写入现有 `tasks.private_data` JSON，保持旧任务兼容。
- 外部 `/v1/videos` API 行为与响应保持不变。

## Layer 1：协议与安全适配

1. 公开只读的 Seedance 模型能力描述，并为四个模型补充能力契约测试。
2. 新增会话用户选择令牌的认证中间件：校验令牌归属、有效状态、额度、IP、用户状态、分组和模型限制，随后复用现有 Token 上下文。
3. 新增工作台 options 接口，只返回有效令牌的脱敏摘要、每个令牌当前可用的 Seedance 模型与模型能力。
4. 新增工作台提交入口，把受控请求路径映射为 `/v1/videos`，复用原生插件、分发与任务提交链路。

## Layer 2：持久化与查询

1. 在 `TaskPrivateData` 增加版本化的工作台请求快照：提示词、模型、生成参数、工具和素材逻辑引用。
2. 提交中间件严格解析、校验 Seedance payload，并把请求快照放入上下文；任务成功持久化时写入私有 JSON。
3. 新增当前用户的工作台任务列表和详情接口：只返回自己的 Seedance 任务、公开任务字段、计费、媒体数量、可播放 artifact，以及属于该用户的请求快照。
4. 过期素材在详情中标记为不可复用，保留历史引用，不返回渠道密钥和上游私有诊断。

## Layer 3：前端工作台

1. 新增 `/video-generation` 路由和通用侧栏入口。
2. 使用 React Query 拉取 options、临时素材和历史任务；使用 React Hook Form + Zod 做参数校验。
3. 提供明确的 Key、模型、模式、提示词、分辨率、比例、时长、音频、水印、Web Search 选择。
4. 提供图片/视频/音频素材选择器，支持素材库、公网 URL 和复用现有 COS 直传；上传完成自动加入请求。
5. 生成后结构化展示状态、进度、请求参数、素材计数、耗时、计费、错误和视频预览/下载；支持从历史请求恢复表单，过期素材要求替换。
6. 补充中文和英文文案；其他语言使用项目同步脚本生成 fallback。

## 测试与验收

- 后端：令牌越权、令牌失效、模型限制、能力配置、payload 校验、请求快照 JSON 兼容、任务归属与历史投影。
- 前端：表单模式互斥、模型能力联动、素材数量限制、过期素材复用阻止、提交 payload、加载/错误/空状态。
- 运行受影响 Go 测试、前端 Vitest、typecheck、涉及文件 lint、生产构建。
- 检查 `git diff` 只包含本任务；双模型审查工具若仍不可用，在 review.md 如实记录并完成本地人工与自动化审查。
