# 模型级币种与模型广场分组图标

## 目标

- 模型元数据持久化 `USD` 或 `CNY`，默认 `USD`。
- `/models/metadata` 新增和编辑模型时可设置计费币种。
- `/api/pricing` 以模型元数据币种为唯一运行时来源，模型广场与产品报价支持混合币种展示。
- 移除按模型名判断 CNY 的运行时硬编码；历史直接人民币模型通过一次性迁移保留原有币种。
- `/pricing` 分组筛选展示配置的分组图标，筛选行为与倍率不变。

## 兼容规则

- 旧模型记录默认迁移为 `USD`。
- 已有 MiniMax M3、Qwen 3.5 Flash/Plus、StarAI Seedance 和 Molii Grok 直接人民币价格模型在迁移时回填 `CNY`。
- 管理员后续显式修改币种后，不再被模型名或插件价格矩阵覆盖。
- 公开定价接口新增独立的安全分组元数据字段，不改变现有 `usable_group` 数据结构。

## 验收

- 后端模型创建、更新、查询和定价接口正确保留币种。
- 非法币种被拒绝或规范化为明确错误，不静默接受。
- 前端新增/编辑表单正确保存并恢复币种。
- 模型广场和报价计算器按接口币种显示。
- 分组筛选在桌面及移动布局展示配置图标，无图标时正常回退。
- PostgreSQL 迁移可重复执行；相关 Go、Vitest、类型检查与构建通过。

## 分析限制

- CCG 配置的 antigravity 与 Claude wrapper 路径不存在，两路外部分析调用均退出 127；不得声称已获得外部模型分析结果。
