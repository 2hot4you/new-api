# 需求

- 修复管理员为 `glm-5.3` 保存定价时报 `model pricing changed; reload before saving` 的问题。
- 同时修复“未设置价格模型”中其他仅有模型元数据、尚无价格记录的模型保存时出现相同误报的问题。
- 保留真正并发修改时的乐观锁冲突保护。
- 不改变实际计费、货币换算或既有定价表达式语义。

# 根因假设

全量定价快照只枚举已有价格记录和内置表达式，没有枚举仅存在于模型元数据表中的精确模型。前端因此使用 USD 空白版本作为回退；CNY 元数据模型在服务端使用 CNY 参与版本计算，导致保存必然被判定为版本冲突。

# 验收

- 全量快照包含尚未配置价格的精确模型元数据条目。
- 条目的版本包含其真实 `billing_currency`，用该版本首次保存成功。
- 前缀/正则等非精确元数据不进入可编辑定价快照。
- 原有冲突检测测试仍通过。
