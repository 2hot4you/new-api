# CI/CD 网络重试需求

- `development`、`production-molii`、`production-ixiaozu` 共用相同的有限次数网络重试策略。
- Docker daemon 代理只存在于 `aigc.ixiaozu.cn` 主机，不向工作流、Molii 主机或业务容器注入代理。
- 可安全重试的步骤包括 SSH 连通性、远端 GHCR 登录、SCP 上传、镜像拉取和只读健康检查。
- `docker compose up`、回滚、数据库备份、迁移和其他可能产生副作用的步骤不得由通用重试器重复执行。
- 每次失败必须记录尝试次数、退出码和下一次等待时间；达到上限后保留非零退出码。
- 保留现有部署锁、不可变镜像摘要、健康检查和失败回滚语义。
- 当前部署仍为单容器切换，允许镜像更新时出现短暂中断。
