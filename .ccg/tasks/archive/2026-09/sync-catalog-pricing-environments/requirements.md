# 模型广场与定价目录同步需求

## 目标

提供可重复执行的命令行工具，将开发环境的厂商、模型元数据和模型基础价格同步到 `molii.co` 与 `aigc.ixiaozu.cn` 对应的独立 PostgreSQL 数据库。

## 安全边界

- 默认只生成差异预览，不执行写入。
- 写入必须显式使用 `apply`，并提供预览返回的确认摘要。
- 写入前保存目标环境受影响数据的 JSON 快照。
- 不删除目标环境的厂商或模型记录。
- 不迁移渠道、渠道能力、API 密钥、用户、钱包、余额、日志、任务、临时素材、Redis 数据及站点品牌配置。
- 不同步分组定义、分组倍率、分组元数据或用户分组。
- 不打印数据库连接串及其中的密码。

## 同步内容

- 厂商：按名称匹配，复制描述、图标、状态和展示顺序。
- 模型：按 `model_name` 匹配，复制模型广场使用的完整持久化元数据；通过厂商名称重新映射目标 `vendor_id`。
- 通用模型价格：同步模型倍率、补全倍率、缓存、图片、音频、按次价格和阶梯计价表达式。
- 特殊价格：同步 `starai_video_price.*`、`molii_grok_price.*` 和 `task_pricing_setting.*`。
- 工具价格：同步 `tool_price_setting.prices` 和 `molii_grok_tool_price.*`。
- 对于已纳入同步的模型，价格映射以源快照为准；保留目标环境独有模型的价格项。

## 可见性说明

同步目录不会复制渠道。目标环境只有在自身存在启用渠道和对应模型能力时，模型才会出现在 `/pricing`。

## 交互

- `export`：从源数据库导出版本化快照并显示 SHA-256 摘要。
- `plan`：比较快照与目标数据库，输出机器可读 JSON 差异和确认摘要，不写数据库。
- `apply`：要求输入快照、确认摘要和备份目录；摘要不匹配则拒绝写入。
