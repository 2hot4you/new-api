# 临时素材刷新与类型筛选

## 需求

- 单个素材刷新时查询对应的用户或管理员详情接口。
- 使用接口返回的最新素材直接更新当前卡片，包括状态和 `verified_at`。
- 刷新期间只禁用并旋转当前素材的刷新按钮。
- 刷新成功和失败均提供明确提示；失败时保留原数据。
- 将原类型下拉框替换为“全部 / 图片 / 视频 / 音频”四个紧凑卡片按钮。
- 默认选择“全部”，并继续与素材 ID、时间范围筛选组合使用。
- 重置筛选恢复“全部”；其他页面行为保持不变。

## 验收标准

- 普通用户和管理员使用各自正确的刷新端点。
- 刷新响应能即时替换匹配素材，不额外刷新完整列表。
- 类型筛选具有可访问的按下状态，点击后切换当前类型。
- 相关测试、类型检查、i18n 检查和涉及文件 lint 通过。
