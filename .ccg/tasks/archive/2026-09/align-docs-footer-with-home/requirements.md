# 将文档站 Footer 调整为首页同款

## 需求

- `/docs` 文档站 Footer 使用 Molii 首页 Footer 的视觉、信息层级和响应式布局。
- 保留 New API（QuantumNous）归属信息。
- 文档内部链接必须兼容 `/docs/` 子路径部署。
- 平台功能链接必须返回同源的平台路由，不被 Docusaurus `baseUrl` 改写。
- 不修改文档正文、导航栏、后端、数据库或其他页面。

## 实现边界

- Docusaurus 与主站是独立前端构建，使用 Docusaurus Footer 主题覆盖实现同款结构。
- 使用文档站已有 Molii 品牌资源，不引入新的运行时接口和第三方依赖。
- 厂商区使用当前模型目录中已公开的厂商，并以轻量品牌字标展示，避免新增图标依赖。

## 验收标准

- Footer 显示品牌、产品、开发者、厂商、支持五栏及底部版权行。
- 桌面和移动端不产生页面级横向滚动。
- `/docs/` 子路径构建通过，链接目标正确。
- 文档站测试、构建、禁用词与敏感信息检查通过。
