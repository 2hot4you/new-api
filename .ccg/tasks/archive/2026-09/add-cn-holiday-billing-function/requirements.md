# 中国节假日计费与管理员计费日历

## 目标

- 在计费表达式中提供 `is_holiday("CN", "Asia/Shanghai")`。
- 使用版本化的中国国务院办公厅节假日安排数据，真实影响计费结算；首期覆盖从 2026-10-01 开始，之前日期均视为未覆盖。
- 未配置国家或年份返回 `false`，遵循“宁可多收、不少收”。
- 管理员后台新增独立的计费日历，可按模型查看每天的计费档位和分钟级价格时段。
- 日历分别展示普通工作日、普通周末、法定休息日、调休工作日；日历分类不擅自改变模型表达式语义。
- 可将当前选择模型、当前显示月份的计费时段导出为 Apple Calendar 可导入的 `.ics` 文件。

## 验收标准

- Go 与 Web 对同一日期的 `is_holiday` 结果一致。
- 法定休息日为 `true`，调休工作日、普通周末、普通工作日为 `false`。
- 未覆盖年份明确提示且运行时返回 `false`。
- 2026-10-01 以前明确显示为未覆盖且 `is_holiday` 返回 `false`。
- DeepSeek 示例在普通工作日显示 09:00–12:00、14:00–18:00 高峰，其余低峰；法定休息日全天低峰。
- 只有管理员及以上角色可以打开计费日历，数据不依赖公共定价页是否启用。
- 页面只读；模型价格仍在现有模型定价菜单维护。
- Apple 日历导出只包含覆盖范围内、可安全求值的日期和时段，并携带档位、价格及日历分类说明。
