# Seedance 表达式定价需求

## 目标

管理员只维护“模型定价 → Seedance 2.0”标签页中的价格矩阵。保存后，系统自动为四个 Seedance 模型生成对应的任务计费表达式；预扣、最终结算、公开价格和消费日志统一读取表达式。

## 范围

- 保留现有 Seedance 2.0 价格矩阵和字段。
- 保存矩阵时原子更新四个模型的 `billing_mode=tiered_expr` 与 `billing_expr`。
- Molii Volcengine Imagine API 渠道向表达式提供 `tokens`、`resolution`、`video_input` 用量事实。
- 提交阶段使用本地估算 Token；完成阶段用上游实际 Token 和实际分辨率覆盖估算值。
- 原 `starai_video_price` 配置作为矩阵编辑数据与表达式生成输入，不再形成独立运行时价格真相。
- 管理员无需在“通用模型”中手写或维护这四个模型的表达式。

## 验收

- 四个模型的全部分辨率/参考视频组合生成正确表达式。
- 保存失败时价格矩阵与表达式均不发生部分更新。
- Molii Volcengine Imagine API 渠道可以使用生成的表达式提交和完成结算。
- 最终结算使用实际 Token，多退少补；分组倍率只应用一次。
- 专项标签页重新打开时显示已保存矩阵。
- 通用模型页面不再提示这四个模型“尚未配置任务定价”。
