# StarAI 上游素材 ID 透传需求

- 新建素材时，公开 `id` 必须直接返回上游素材 ID，不再生成新的 `asset-molii-*`。
- 用户通过 `asset://<upstream-id>` 查询、刷新、删除或提交视频时，必须先按当前登录用户校验本地绑定。
- 用户 A 不得使用、查询、刷新或删除用户 B 的素材，即使 A 知道 B 的上游素材 ID。
- 同一用户的不同 API Key 可以共享该用户创建的素材。
- 内部继续记录原始渠道 ID 与渠道 Key 指纹，防止跨上游 Key 错误查询。
- 现有 `asset-molii-*` 在其剩余 168 小时生命周期内继续可用，新素材只返回上游 ID。
- 不迁移用户、渠道、日志或其他业务数据。
