# Seedance 视频工作台编辑与付费确认优化

## 需求

- API 密钥仅以 `sk-abcdxxxxefgh` 格式脱敏展示，不需要手动输入。
- 默认选中最新创建且拥有当前 Seedance 模型权限的 API 密钥，仍允许用户切换其他可用密钥。
- 提示词输入区域高度至少扩大到现有三倍。
- 输入 `@` 弹出素材面板，按图片、视频、音频分类，支持按素材名称或 `asset_id` 模糊搜索，并按最新上传排序。
- 鼠标点击素材即可引用其 `asset_id`；编辑区显示素材缩略图和素材名，悬停可预览。
- 已通过素材以淡绿色展示；未通过、失败、过期或处理中素材以红色告警并阻止任务发送。
- 同一素材重复引用时复用已有引用，不重复加入请求媒体。
- 生成模式选项使用中文文案。
- 提交前二次确认这是付费请求，显示复用真实计费逻辑计算的预估费用；取消不创建任务、不扣费。

## 约束

- 素材继续受当前用户所有权隔离。
- 预估费用不得在前端硬编码单价，不调用上游、不预扣额度。
- 最终结算仍以任务实际完成后的计费结果为准。
