# API 密钥限制明细与准确时间

## 用户目标

- 模型限制列不再只显示数量；点击后弹出完整模型清单。
- 每个模型条目展示 Provider 与模型 ID。
- IP 限制列点击后弹出完整 IP 地址清单。
- 创建时间和最后使用时间直接显示准确时间，不再以相对时间作为主显示。

## 约束

- 不修改令牌后端契约、限制语义或授权逻辑。
- 保持表格紧凑，详情在键盘可操作、适应视口的弹层中显示。
- Provider 信息来自现有公开模型目录；目录缺失或加载失败时仍显示模型 ID，并安全降级为未知 Provider。
- 所有新增用户可见文案完整支持现有语言。
- 先写失败测试，再实施。
