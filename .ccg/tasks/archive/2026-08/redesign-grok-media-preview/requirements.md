# Grok 媒体预览重构需求

- 图片预览采用桌面双栏布局：左侧展示媒体，左侧底部展示图片参数；右侧展示计费项、计费公式与必要操作。
- 视频预览保持媒体优先，并补充与图片一致的下载入口和必要的计费信息。
- 图片和视频均提供用户可直接使用的下载按钮。
- 下载继续使用已经过后端严格校验的临时结果 URL；不得重新引入服务端 GET/HEAD、COS 转存或 Redis 清理队列依赖。
- 移动端降级为纵向排列，预览在前、参数与计费在后。
- 保留临时链接过期提示、鉴权、无 referrer、错误脱敏与现有计费契约。
- 多图结果逐张预览、逐张下载；不擅自增加打包下载。
- 所有新增用户文案覆盖现有前端语言。
