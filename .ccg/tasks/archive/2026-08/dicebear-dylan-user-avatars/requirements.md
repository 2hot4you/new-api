# DiceBear Dylan 当前用户头像与首页搜索层级

## 用户头像

- 仅替换当前登录用户在顶部账户菜单、个人资料页和移动端侧栏中的头像。
- 不修改使用日志、任务日志和管理列表中的用户标识。
- 使用 DiceBear Dylan 风格，用户 ID 作为稳定且不含邮箱、用户名的种子。
- 图片不可用时保留原首字头像回退。
- 不新增数据库字段或用户头像上传能力。

## 首页搜索

- `127.0.0.1:3000` 继续作为本地唯一对外访问入口。
- 搜索建议必须显示在后续 CTA 按钮之上，不得被按钮穿透或遮挡。
- 不执行生产构建；验证 3000 实时代理 3001 的开发资源。
