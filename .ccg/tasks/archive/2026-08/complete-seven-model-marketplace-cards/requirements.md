# 七个文本模型卡片补全需求

## 范围

- 为 `deepseek-v4-flash-202605`、`deepseek-v4-pro-202606`、`glm-5.2`、`kimi-k3` 注册默认模型简介。
- 为上述四个模型以及 `minimax-m3`、`qwen3.5-flash`、`qwen3.5-plus` 在模型广场卡片中展示明确的计费说明。
- 固定价格模型说明按输入、输出与缓存 Token 用量计费，价格单位跟随页面当前 Token 单位。
- 阶梯价格模型说明按完整输入长度分档，并显示档位数量；各档价格继续由详情页完整展示。

## 约束

- 不修改任何模型定价数值或计费表达式。
- 不影响其他模型的卡片布局与文案。
- 自定义数据库描述优先于默认简介。
- 使用现有默认模型元数据和 i18n 机制，不持久化新的运营数据。
