# 需求

- 新模型 ID 出现在已启用渠道能力后，自动出现在模型元数据管理页。
- 使用 models.dev 的公开目录为新模型补齐可验证的规格、模态与能力资料。
- 数据库中的管理员配置始终优先；仅补空字段，`sync_official=0` 时完全跳过。
- `/pricing` 继续只读取数据库元数据与 Molii 本地计费设置，不直接请求外部目录。
- 不从外部目录同步价格、倍率或计费表达式。
- 外部目录不可用、数据无效或找不到可信厂商时，不影响渠道保存、服务启动和已有模型广场。
- 同步在后台进行，避免阻塞渠道缓存刷新。
- 提供可关闭、可调整周期和超时的 `.env` 示例，不包含密钥。
- 不引入 `grok-imagine-video-1.5-preview`。
