# 审查结果

## 根因

搜索结果超过 Hero 区域底边时受到 `overflow-hidden` 裁剪，后续“已启用模型”和模型厂商容器因此显示在搜索结果上方。

## 修复

- Hero 改为允许搜索结果纵向溢出。
- Hero 建立高于后续首页板块的独立层叠上下文。
- 搜索区域继续保持高于 Hero 内按钮的层级。

## 验证

- 新增长列表越过 Hero 边界的层级契约测试。
- 使用多条匹配结果实机检查，列表底部命中元素仍为搜索选项。
- `127.0.0.1:3000` 与内部热更新端口返回的 HTML 和前端脚本哈希一致。
- 定向测试、类型检查、格式检查和范围内 lint 通过。
