# Molii AIGC Demo 常驻运行需求

- Demo 作为独立本地服务后台常驻，不影响 `127.0.0.1:3000` 的 New API。
- 现有 `127.0.0.1:8787` 已被其他 Demo 占用，本服务使用 `127.0.0.1:8788`。
- Go、HTML、CSS、JavaScript 或 module 文件更新后自动构建并重启。
- 浏览器打开的 Demo 检测到服务实例变化后自动刷新，加载新前端资源。
- SQLite 使用固定路径，重启不丢环境、任务或日志。
- 加密主密钥放入 macOS 登录钥匙串，不写入仓库、日志或 plist。
- 使用 LaunchAgent 登录启动和异常拉起。
