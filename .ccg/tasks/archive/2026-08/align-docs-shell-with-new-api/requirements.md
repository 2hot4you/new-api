# Requirements

- `/docs`、`/docs/` 与文档品牌链接只进入 `/docs/quick-start`，旧文档首页不再可达。
- 文档 Header 与 Footer 使用 Docusaurus 官方默认主题，不复刻 New API 主站样式。
- Header 保留文档站自身的六个顶层导航与 Molii 标识。
- 保留文档搜索，移除明暗模式入口并固定浅色模式。
- Footer 使用 Docusaurus 默认布局和精简的开发者资源栏目。
- 文档正文、左侧目录、移动端导航和 `/docs/` 子路径部署不得回归。
- 用契约测试、浏览器测试、生产构建和内部链接检查验证。
