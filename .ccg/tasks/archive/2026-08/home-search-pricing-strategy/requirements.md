# Requirements

- 首页供应商 Logo 跑马灯遵循公共定价接口返回的供应商排序；双向滚动仅改变动画方向，不反转业务顺序。
- 首页搜索只按模型 ID 与供应商名称进行不区分大小写的子串匹配；单个英文字母、数字或中文字符即可触发。
- 首页搜索不限制六条结果；结果超出可视区域时在下拉区域内滚动展示全部结果。
- 模型广场从 `billing_mode` 与 `billing_expr` 推导计价策略，不依赖模型 ID 硬编码，也不改变实际计费表达式。
- `len` 条件显示为按单次请求完整输入 Token 总数分档，并明确不是累计用量。
- `hour()` 条件显示为按请求时段计价，展示时区、时间窗口与倍率。
- 卡片使用简洁计价策略摘要；详情页展示结构化计价依据与价格规则。
- 所有新增用户文案支持现有前端语言。
