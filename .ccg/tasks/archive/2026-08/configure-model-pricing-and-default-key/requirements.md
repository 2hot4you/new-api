# 三模型计费、模型广场与默认 Key

## 三个模型

只处理以下精确模型 ID：

- `minimax-m3`
- `qwen3.5-flash`
- `qwen3.5-plus`

价格单位均为人民币元/百万 tokens。必须使用系统已有分段表达式能力，并同步当前本地数据库配置。

### minimax-m3

- 输入 tokens `<= 512K`：输入 2.1、输出 8.4、缓存命中 0.42。
- 输入 tokens `> 512K`：输入 4.2、输出 16.8、缓存命中 0.84。

### qwen3.5-flash

- 输入 tokens `<= 128K`：输入 0.2、输出 2、缓存命中 0.02。
- `128K <` 输入 tokens `<= 256K`：输入 0.8、输出 8、缓存命中 0.08。
- `256K <` 输入 tokens `<= 1M`：输入 1.2、输出 12、缓存命中 0.12。

### qwen3.5-plus

- 输入 tokens `<= 128K`：输入 0.8、输出 4.8、缓存命中 0.08。
- `128K <` 输入 tokens `<= 256K`：输入 2、输出 12、缓存命中 0.2。
- `256K <` 输入 tokens `<= 1M`：输入 4、输出 24、缓存命中 0.4。

模型广场必须为每个模型补齐：卡片简介、人民币阶梯价格表、详情概览、性能信息和真实 `/v1/chat/completions` API 示例。不得改动其他模型。

## 受保护默认 Key

- Token 表新增明确的 `is_default` 布尔字段，默认 false。
- 所有普通用户自助注册路径（密码、OAuth、微信等首次建号）强制创建且仅创建一条 `is_default=true` 的默认 Key，不再依赖 `GENERATE_DEFAULT_TOKEN`。
- 管理员创建用户、初始化管理员和存量用户不补建。
- 用户可编辑、重置、启用或禁用默认 Key。
- 单删默认 Key 返回稳定错误 `default_token_delete_forbidden`。
- 批量删除只要包含默认 Key就整批原子拒绝；普通 Key仍可删除。
- 前端显示默认标记，隐藏单删入口，并禁止默认 Key进入批量删除选择。
- 用户与默认 Key 必须在同一数据库事务创建；Key 创建失败回滚用户。
- 提供 GORM migration 与显式 PostgreSQL 迁移文件，不提交真实密钥。
