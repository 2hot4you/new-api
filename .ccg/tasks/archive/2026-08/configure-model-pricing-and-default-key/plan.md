# 三模型计费与默认 Key 实施计划

1. 计费工作流：确认表达式 DSL 与实际 token 变量，先写边界失败测试，再增加三模型表达式、默认模型目录与本地数据库配置。
2. 模型广场工作流：基于 MiniMax、阿里云官方资料补齐三个模型的目录元数据、价格矩阵、详情和 Chat Completions API 示例。
3. 默认 Key 工作流：先写迁移、注册事务和删除保护失败测试，再增加 `is_default`、自助注册服务与前端限制。
4. 主代理审查两个工作流的差异与文件冲突，运行相关定向、全量、迁移、类型与接口测试。
5. 重启本地开发环境并验证模型价格页面、模型详情和 API Key 页面。
