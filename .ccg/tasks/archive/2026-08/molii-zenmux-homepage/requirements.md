# Molii ZenMux 风格首页需求

## 已确认范围

- 首页参考 ZenMux 当前首页的信息密度、板块节奏、响应式布局和动效语言，但使用 Molii 品牌、现有字体与炭灰主色。
- 产品定位不是单一多模态创作平台，而是同时覆盖 LLM 与图片/视频生成能力的统一 AI 模型平台。
- LLM 示例包括 DeepSeek、GLM、Qwen、Kimi、MiniMax、MiMo 等当前已接入模型。
- 多模态能力包括 Seedance 视频生成与 Grok Imagine 图片/视频生成。
- 使用真实能力替换 ZenMux 的营销板块：统一 API Key、模型广场、透明计费、生成记录、异步任务、使用日志和 API 接入。
- 没有真实数据来源的保险赔付、客户案例和虚构平台指标不展示。
- 保留模型厂商 Logo 双排、反向、无限无缝滚动效果。
- 不恢复主题切换功能。

## 数据方案

- 厂商 Logo 完全由当前公开模型元数据和启用模型动态生成，不维护首页精选名单。
- Hero 输入框用于模型 ID、厂商和能力搜索，提交后跳转模型广场，不发起付费请求。
- “动态与更新”替换为按模型发布日期自动生成的“最新上线模型”。
