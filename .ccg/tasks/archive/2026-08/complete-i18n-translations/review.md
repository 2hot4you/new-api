# 审查结果

## 根因

中文语言包包含 5,732 个键，比法语、日语、俄语、越南语各多 190 个键；繁体中文少 70 个键，英文少 12 个键。同步工具会自动选择键最多的语言包作为基准，因此一次同步会把这些历史差异全部展开为大批修改。

## 处理结果

- 法语、日语、俄语、越南语各补齐 190 条对应语言翻译。
- 繁体中文补齐 70 条翻译。
- 英文补齐 12 条源文案。
- 对机器初稿中的模型术语、API 名称、Molii 品牌、秒数单位和模型 ID 做了人工修正。
- 新增语言包键集合一致性测试及 `i18n:check` 命令。
- 同步报告中全部语言的 `missingCount` 均为 0。

## 验证

- 7 个语言包均包含 5,732 个翻译键。
- 新增翻译无空值、无意外英文回退。
- 新增翻译的 `{{变量}}` 与英文源文案完全一致。
- `bun run i18n:check` 通过。
- TypeScript 类型检查通过。
- 格式检查与定向静态检查通过。
- `git diff --check` 通过。
- 本地 3000 服务返回 HTTP 200。

## 范围说明

同步报告仍会识别部分历史文案与英文值相同；这些是本任务之前已存在的翻译质量提示，不属于本次 190 个缺失键。本次未扩大范围重译全部历史语言包。

按用户既有要求，未调用 antigravity 或 Claude。
