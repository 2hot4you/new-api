# API 密钥限制摘要与复制交互

## 模型限制

- 表格摘要按令牌配置顺序展示最多五个模型自身的 Lobehub 图标，超过五个追加省略号。
- 弹层按 Provider 分组：分组标题使用 Provider 图标与名称，模型条目使用模型自身图标与完整模型 ID。
- 点击模型条目复制单个模型 ID。
- 提供“全部复制”，按令牌配置顺序使用英文逗号连接全部模型 ID。

## IP 限制

- 表格摘要展示第一个 IP/CIDR；存在更多限制时追加省略号。
- 弹层以可点击徽标展示全部 IP/CIDR，点击复制单项。

## 约束

- 复用 `/api/pricing` 的 `model.icon`、Vendor 元数据及现有 Lobehub 图标组件。
- 不新增后端字段，不改变令牌权限或限制语义。
- 复制反馈、无元数据降级、键盘操作和现有语言均需覆盖。
- 使用 TDD，先观察新测试失败。
