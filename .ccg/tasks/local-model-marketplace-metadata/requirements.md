# 模型广场本地元数据配置需求

## 已确认

- 不再从 models.dev 或其他外部目录同步模型资料。
- 管理员在 `/models/metadata` 的模型编辑抽屉中输入或选择模型广场资料。
- 模型资料允许保存为草稿。
- 使用独立的“在模型广场展示”开关；发布时执行完整性校验。
- 模型广场仍从现有计费、渠道能力和性能数据中读取动态信息。
- 模型资料、计费配置、渠道配置和运行数据保持边界分离。
- 模型资料采用公共字段加分类条件字段。
- 中文简介必填，英文简介可选；其他语言缺失时回退中文。
- LLM 要求上下文、最大输出和支持参数；图片与视频按生成能力要求对应规格。
- 采用兼容迁移保留现有资料，完成数据库回填后移除内置目录与 models.dev 元数据同步。
- 编辑抽屉按公开资料、模态能力、发布状态和高级配置分区。
- 公开列表只返回资料完整、显式发布且具有有效价格、分组和端点的模型。
