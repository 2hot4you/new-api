# 模型广场目录式重构需求

## 已确认

- 采用方案 B：高度还原 ZenMux 的高密度、细边框、表格式模型目录布局。
- 保留 Molii 导航、品牌、字体、颜色语义与真实数据源，不复制第三方品牌元素，不伪造缺失指标。
- 保留顶部公共导航；移除现有大幅渐变背景、居中大标题和大型搜索框。
- 桌面采用固定左侧筛选栏与右侧目录；右侧包含标题统计、动态分类、紧凑工具栏和三列连续网格。
- 模型单元通过细边框组成连续目录，不使用独立悬浮圆角卡片；平板双列、移动端单列，移动端筛选进入抽屉。
- 页面采用高密度模型目录结构，参考 ZenMux 的信息架构，但沿用 Molii 品牌、设计令牌和真实数据。
- 取消按厂商分组展示，所有模型进入统一列表。
- 左侧提供厂商筛选。
- 默认按模型发布时间从新到旧排序。
- 缺少发布时间的模型排在有发布时间模型之后，并以模型 ID 稳定排序。
- 点击模型进入独立详情页，使用现有 `/pricing/{modelId}` 路由，不再打开右侧抽屉。
- 详情页按目录式页面重排，但继续复用现有真实定价、性能、能力和 API 数据。
- 顶部模型分类根据实际数据动态展示，首期包括全部、文本、图片、视频；数量为零的类型隐藏，未来新增类型自动出现。
- 列表卡片采用紧凑价格摘要：LLM 显示输入、输出、缓存单价；Grok、Seedance 等复杂价格显示分档计费与最低起始价格。
- 完整价格矩阵只在独立模型详情页展示。
- 模型卡片依次展示厂商 Logo、模型名称和 ID、简介、输入输出模态、紧凑定价、核心能力、发布时间、端点协议和真实性能状态。
- 整张卡片可点击并进入独立详情页，不保留单独详情按钮。
- 不展示调用 Token 总量、缓存命中率、供应商数量等当前没有可靠来源的字段；缺少性能数据时明确显示暂无数据。
- 计价单位统一为 `¥ / 1,000,000 Token`、`¥ / 张`、`¥ / 秒`。
- 左侧筛选包含输入类型、上下文区间、厂商、能力、协议、计费类型、分组和标签，全部根据真实模型数据动态生成。
- 顶部工具栏包含搜索、动态模型分类、标准/充值价格显示和排序。
- 默认按最新发布时间排序，并支持名称、价格升序和价格降序；不加入没有正式业务字段的折扣、免费筛选。
- 不展示 Molii 当前没有可靠数据来源的调用量、缓存命中率、供应商数量等信息。
