# Grok 模型广场价格总览表设计

## 目标

在模型广场列表的 Grok 模型卡片中增加与 Seedance 价格矩阵一致的结构化总览，让用户无需进入详情即可看懂不同分辨率、输出类型和输入素材的价格。

## 展示范围

本次只修改模型广场列表卡片。详情弹窗现有 Grok 定价区、后台价格配置页面、实际计费逻辑及 API 契约保持不变。

## 表格结构

所有 Grok 卡片使用统一视觉语言和三列布局，但列含义随模型类型变化：

- 图片模型：`输出分辨率｜图片输出｜图片输入`。
- `grok-imagine-video-1.5`：`输出分辨率｜视频输出｜图片输入`。
- `grok-imagine-video`：`输出分辨率｜视频输出｜媒体输入`；媒体输入单元格分两行展示图片输入价和视频输入价。

每个价格在单元格中直接带单位，例如 `¥0.08 / 秒` 或 `¥0.01 / 张`。表格使用后端返回的 `molii_grok_pricing.output_prices`、`image_input_price` 和 `video_input_price`，不复制后台默认值到前端组件。

## 卡片信息层级

- 卡片标题下方不再显示用于系统按次计费的 `¥1 / 请求` 锚点。
- 改为“按分辨率和输入类型计费”的中性说明。
- 卡片底部不再为 Grok 模型显示 `1M` Token 单位。
- 描述、分组、计费模式、性能摘要和详情入口保持现状。

## 组件边界

新增 Grok 专用的紧凑价格矩阵组件，职责仅为把 `MoliiGrokPricing` 渲染成表格。价格行构建逻辑放在纯 TypeScript 模块中，便于测试模型差异和缺失数据行为。`ModelCard` 只负责识别 `molii_grok_pricing` 并选择价格摘要和矩阵，不修改 Seedance 或通用模型分支。

## 异常状态

当 `molii_grok_pricing` 缺失时维持通用价格展示；当定价对象存在但没有可用输出行时，矩阵显示“价格信息暂时不可用”，不虚构默认价格。

## 测试与验证

- 测试图片模型、旧版视频、Video 1.5 的列和价格行。
- 测试旧版视频媒体输入单元格同时包含图片和视频输入单位。
- 测试 Grok 卡片不再渲染按次锚点和 Token 单位的派生条件。
- 运行定向测试、类型检查、格式检查和生产构建。
- 重建并重启本地常驻后端，在 `127.0.0.1:3000/pricing` 验证四个 Grok 卡片与 Seedance 卡片的视觉一致性。

## 设计确认

用户选择方案 A“按模型定制三列表”，并明确允许跳过设计文档人工评审，直接进入实施。
