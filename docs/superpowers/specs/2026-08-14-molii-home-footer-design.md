# Molii 新版首页 Footer 设计

## 范围

为默认 Molii 首页新增专属 Footer。控制台、其他公开页面及现有共享 `Footer` 组件保持不变。若后台配置了自定义 Footer HTML，首页继续使用现有共享 Footer 渲染该配置，避免覆盖运营设置。

## 视觉

Footer 使用偏深炭灰背景和白色主文字，以中性灰展示说明与次级链接，作为浅色首页的明确收尾。顶部使用宽松留白和细灰分隔线，不引入彩色渐变。链接悬停仅提高亮度并产生轻微水平位移，遵守系统减少动态效果设置。

桌面端采用品牌区加三列链接；移动端改为纵向排列，链接保持足够点击面积且不横向溢出。

## 信息架构

### 品牌区

- Molii Logo 与品牌名。
- 品牌说明：通过统一 API Key 连接语言、图片与视频模型，并提供透明计费和完整生成记录。
- 一个进入模型广场的主入口。

### 产品

- 模型广场 `/pricing`
- API Key `/keys`
- 生成记录 `/usage-logs/task`
- 使用日志 `/usage-logs/common`

### 开发者

- 快速开始，基于系统配置的文档站地址指向 `/getting-started/quickstart`。
- API 文档，基于系统配置的文档站地址指向 `/api-reference`。
- 模型与价格 `/pricing`

### 支持

- 关于 `/about`
- 用户协议 `/user-agreement`：仅在系统开启时显示。
- 隐私政策 `/privacy-policy`：仅在系统开启时显示。

### 底栏

- 当前年份与 Molii 版权。
- New API 开源项目归属链接。
- 系统已有备案信息或自定义底部内容继续由现有配置负责，不在组件内写死。

## 数据与配置

组件通过现有 `useSystemConfig` 和 `useStatus` 获取品牌、Logo、文档地址、Footer HTML 与协议开关。文档子路径通过 URL 解析安全拼接；文档地址未配置时不渲染开发者文档链接。不存在的能力或 URL 不渲染，不使用占位链接。

## i18n

新增 Footer 标题、品牌说明和链接文案键，并同步至现有 `zh`、`zh-TW`、`en`、`ja`、`vi`、`fr`、`ru` 语言文件。中文为产品文案基准，其余语言提供准确简洁翻译。

## 测试

- 首页默认模式渲染专属 Footer，其他页面共享 Footer 不变。
- 后台自定义 Footer HTML 存在时回退现有共享 Footer。
- 链接只指向真实路由或配置 URL。
- 协议链接随开关显示或隐藏。
- 桌面与移动结构不溢出，深炭灰样式契约稳定。
