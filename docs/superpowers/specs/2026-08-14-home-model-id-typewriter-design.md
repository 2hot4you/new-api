# 首页模型 ID 打字机占位提示设计

## 目标

首页搜索框在空闲状态下循环展示当前已启用模型的真实模型 ID，帮助用户直观看到可搜索内容，同时保持现有搜索交互不变。

## 数据来源

组件直接使用首页已传入的启用模型目录，按当前目录顺序提取非空且去重的 `model_name`。不新增静态模型清单，也不请求新的接口。

当目录尚未加载或没有可用模型 ID 时，显示原始占位提示“搜索模型、厂商或能力”。

## 动画状态

动画只在输入值为空且输入框未聚焦时运行：

1. 逐字输入当前模型 ID，完整输入阶段不超过三秒。
2. 完整文本短暂停留。
3. 模拟 Delete 键，从末尾逐字删除到空字符串。
4. 切换到下一个模型 ID并循环。

输入框获得焦点时立即停止并重置动画，占位提示恢复为“搜索模型、厂商或能力”。失焦且输入仍为空时，从模型序列继续启动。用户输入内容始终由现有 `query` 状态独立管理，动画只改变 `placeholder`，不会写入输入值、触发搜索或改变结果列表。

## 可访问性与生命周期

- 系统开启“减少动态效果”时不播放逐字动画，仅显示一个静态模型 ID；聚焦时仍恢复原始提示。
- 组件卸载、模型目录变化或焦点状态变化时清理定时器，避免过期更新。
- 不使用覆盖层，不改变输入框、按钮和搜索结果的层叠结构。

## 测试

- 以可控计时器验证输入、停留、逐字删除和切换阶段。
- 验证模型 ID 来自传入目录并去重。
- 验证聚焦后恢复原始提示，失焦空输入后重新运行。
- 验证输入、提交、键盘导航和搜索结果链接保持现状。
