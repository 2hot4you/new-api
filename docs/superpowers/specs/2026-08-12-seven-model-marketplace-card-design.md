# 七个文本模型卡片补全设计

## 目标

模型广场中七个指定文本模型都应有可读的模型简介，并在价格数字之外说明具体计费方式。

## 数据与展示

四个缺失简介的模型通过后端默认元数据返回 `description_i18n_key`，前端继续使用既有的“自定义描述优先、默认翻译回退”规则。

计费说明由前端纯函数根据模型 ID 和已有计费数据生成：

- 固定 Token 价格：说明按输入、输出及缓存 Token 用量计费，并显示当前 `/1M` 或 `/1K` 单位。
- 三个动态阶梯模型：说明按完整输入长度分档计费，并显示解析得到的档位数量和当前单位。
- 其他模型不新增说明，避免扩大变更范围。

完整价格表、表达式和档位详情继续保留在模型详情页，卡片只提供一行紧凑摘要。

## 验证

- Go 单元测试覆盖四个新增默认简介键及范围外模型。
- TypeScript 单元测试覆盖七个模型的计费说明、Token 单位切换和范围外模型。
