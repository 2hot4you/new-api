# 模型广场按厂商换行设计

## 目标

模型广场的卡片保持现有内容和样式，但按厂商连续排列。每个新厂商必须从新的一行开始，不显示额外的厂商标题。

## 布局

- 当前分页得到的模型先按厂商建立稳定分组。
- 厂商顺序取该厂商首个模型在当前筛选、排序结果中的位置。
- 同一厂商内保留现有模型顺序。
- 每个厂商分组渲染为一个独立的响应式网格，沿用现有列数和间距。
- 上一厂商最后一行未铺满时保留空位，下一厂商从下一行开始。
- 移动端仍为单列，因此不会出现额外的视觉占位。

## 厂商识别

优先使用 `vendor_id`，缺失时使用 `vendor_name`。两者都缺失的模型按各自独立分组处理，避免错误地把未知厂商模型归为同一厂商。

## 保持不变

- 不新增厂商标题或分隔文字。
- 不修改模型卡片、价格、性能信息或详情入口。
- 不修改筛选、排序、分页数量与翻页控件。
- 不修改后端接口和模型数据。

## 测试

- 同厂商模型进入同一个分组并保持顺序。
- 不同厂商进入不同分组，顺序由首次出现位置决定。
- 缺少厂商信息的模型不会错误合并。
- 网格继续使用现有响应式列数。
- 模型点击、分页和空列表行为保持现状。
