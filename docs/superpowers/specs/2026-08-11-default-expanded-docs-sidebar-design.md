# Docusaurus 侧栏默认展开设计

## 目标

文档页面首次加载时默认展开“开始使用”和“平台与账户”，其他一级分类继续默认折叠。

## 行为

- 两个目标分类使用 Docusaurus category 的 `collapsed: false`。
- 分类保持可折叠，不设置 `collapsible: false`。
- 不调整分类顺序、页面条目、导航链接或移动端侧栏机制。
- 浏览器测试在新的浏览器上下文中检查目标分类已展开，并检查其他分类仍折叠。

## 验收

- “开始使用”和“平台与账户”的分类按钮初始 `aria-expanded="true"`。
- “开发指南”等其他一级分类初始 `aria-expanded="false"`。
- 用户可以点击目标分类将其折叠。
- 本地文档开发服务热更新后仍在 `127.0.0.1:3100` 正常响应。
- 不执行静态构建或部署。
