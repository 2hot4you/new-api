# Docusaurus 紧凑字号设计

## 目标

将 Molii Docusaurus 文档站的整体视觉尺寸缩小 15%，让正文、标题、导航、侧栏、表格、代码块和基于 `rem` 的间距保持一致比例，解决当前文档页面观感偏大的问题。

## 设计

- 在现有 `docs-site/src/css/fonts.css` 中保留 Serif 字体配置。
- 将文档站根字号设置为浏览器默认字号的 `85%`。
- 依靠 Docusaurus 与 Infima 现有的 `rem` 字号和间距体系完成整体等比缩放，不逐个覆盖组件样式。
- 不使用 `zoom`、`transform` 或 JavaScript 缩放，避免影响布局宽度、滚动区域和浏览器兼容性。
- 不修改颜色、字体族、内容宽度、断点、圆角或页面结构。

## 响应式与可访问性

- 桌面端和移动端使用同一 85% 根字号，满足“整体缩小 15%”的明确要求。
- 保留浏览器缩放能力，不限制用户放大页面。
- 验证导航、侧栏、表格、代码块和移动端菜单没有文字截断或横向溢出。

## 测试与部署

- 先新增样式契约测试，确认根字号必须为 `85%`，并观察测试在样式修改前失败。
- 修改 CSS 后重新运行文档站测试与生产构建。
- 在桌面和移动视口检查首页及至少一个内容较密集的 API 文档页面。
- 将新的静态构建同步到 `Application Support`，保持 `io.molii.docs` 后台服务继续在 `127.0.0.1:3100` 提供访问。

## 验收标准

- 文档站所有主要界面元素相对当前版本整体缩小约 15%。
- 计算后的根字号为浏览器默认字号的 `85%`。
- Serif 字体和等宽代码字体保持不变。
- 桌面端和移动端没有新增溢出、遮挡或不可操作控件。
- `http://127.0.0.1:3100/` 返回 HTTP 200，并展示新构建版本。
