# Molii ZenMux 风格首页设计

## 目标

将 New API 默认首页重构为高信息密度、强品牌感的 Molii 产品首页。视觉节奏、内容层级和动效语言参考 ZenMux 当前首页，但不复制 ZenMux 品牌素材、专有文案、客户案例、保险赔付和没有真实数据来源的平台指标。

Molii 的产品定位同时覆盖 LLM 与多模态创作：用户可通过一个平台探索和调用 DeepSeek、GLM、Qwen、Kimi、MiniMax、MiMo 等语言模型，也可使用 Seedance 和 Grok Imagine 进行图片与视频生成。

## 信息架构

### 1. 公共导航

继续使用现有 `PublicHeader` 和 Molii 品牌。保留主页、控制台、模型广场、排行榜、文档、关于、语言、通知与登录状态。不增加活动通知条，不恢复主题切换或配置抽屉。

### 2. Hero

首屏使用大字号标题、简短产品说明和模型搜索框。搜索框只用于模型与能力探索，不发起模型推理或付费生成。用户可输入模型 ID、厂商或能力关键词，例如 `DeepSeek`、`视频生成`、`grok`；提交后跳转 `/pricing?search=...`。

首屏保留“探索模型”和“API 文档”两个入口。登录用户和未登录用户使用相同的探索入口，不修改 Playground。

### 3. 实时平台概览

从当前公开模型元数据和启用模型列表动态计算模型数量、厂商数量和能力类别数量。数字进入视口后执行一次翻牌动画。接口缺失时使用中性占位，不显示虚构数字。

### 4. 厂商 Logo 跑马灯

厂商数据由 `/models/metadata` 与当前启用模型集合交叉生成，自动去重并优先使用模型元数据中的厂商名称和 Logo。上下两排反向无限滚动；悬停暂停，移动端降低速度；`prefers-reduced-motion` 下改为静态自动换行。

点击厂商跳转 `/pricing?vendor=<vendor>`。新增模型或厂商后首页自动更新，不维护第二份首页名单。

### 5. 核心能力

使用五张纵向大卡片展示 Molii 的真实能力：

1. LLM 统一接入：DeepSeek、GLM、Qwen、Kimi、MiniMax、MiMo 等模型。
2. 图片与视频创作：Grok Imagine 图片/视频、Seedance 视频生成。
3. 一个 API Key：统一鉴权和模型调用入口。
4. 异步任务与生成记录：任务轮询、进度、预览、下载和结果记录。
5. 透明计费与使用日志：请求参数、计费公式、预估与最终费用。

卡片内容使用现有路由和能力，不声称尚未实现的自动容灾、智能路由、保险赔付或全球边缘加速。

### 6. Molii 之道

使用四条大型文字分隔行表达“模型丰富、开发者友好、计费透明、创作优先”。每行包含线性图标，悬停时轻微位移或旋转；移动端不依赖悬停传达信息。

### 7. 最新上线模型

从公开模型元数据按 `released_at` 降序筛选最近三个模型。卡片展示厂商、模型 ID、简介、输入/输出模态和发布日期；点击进入 `/pricing/{modelId}`。缺少发布日期的模型不进入该板块。

### 8. 开始使用

底部使用两张大卡：

- 通过 API 使用：展示真实 Base URL 占位符、Bearer API Key 和 OpenAI 兼容 curl/Python 示例，语言切换只改变代码展示，不发送请求。
- 探索模型广场：展示模型搜索、计费与能力入口，跳转 `/pricing`。

### 9. 页脚

继续使用 Molii 页脚风格，只展示当前存在且普通用户可访问的产品、开发者资源、帮助和政策链接。没有对应页面的入口不展示。

## 数据与降级

首页新增数据适配层，将现有模型元数据和启用模型数据转换为：平台计数、厂商列表、最新模型和能力摘要。各板块通过同一份适配结果消费，避免分别硬编码模型和厂商。

模型元数据失败时：首页 Hero、能力卡、使用方式和页脚仍可显示；实时概览使用短横线；Logo 跑马灯和最新模型板块显示稳定骨架或隐藏空内容，不阻断首页。

现有管理员 `HomePageContent` 自定义 URL、HTML 和 Markdown 覆盖逻辑保持不变；只有未配置自定义首页时才显示新的 Molii 默认首页。

## 动效

- 首屏标题、说明、搜索和按钮分段淡入上移。
- 搜索建议使用高度、透明度和位移过渡。
- CTA 边框使用缓慢旋转的中性高光，不使用刺眼彩虹色。
- 数字统计使用 IntersectionObserver 驱动的单次翻牌。
- 厂商 Logo 使用纯 CSS 无缝循环，两排方向相反。
- 核心能力、理念和最新模型使用滚动进入动画。
- 卡片悬停仅使用 2–4px 位移、边框增强和图标微动。
- 所有循环与滚动进入动画尊重 `prefers-reduced-motion`，禁用后直接显示最终状态。

## 响应式与可访问性

桌面使用宽屏分区和双列能力卡；平板缩小间距；移动端全部单列，搜索框、按钮和代码卡自适应。跑马灯在移动端降低速度，理念区保持完整文字。

交互元素使用语义化链接、按钮和表单；搜索建议支持键盘上下选择、Enter 提交和 Escape 关闭；滚动内容不作为唯一信息来源；图标具备可访问名称或标记为装饰。

## 测试与验收

- 为首页数据适配、搜索跳转、最新模型排序、厂商去重和 reduced-motion 契约编写测试。
- 验证元数据错误和空数据降级。
- 运行前端测试、类型检查、格式检查和本次修改文件 lint。
- 在本地开发环境检查桌面、平板和移动端，无水平溢出。
- 检查动效、悬停、键盘搜索、亮暗模式以及 reduced-motion。
- 不执行生产构建。
