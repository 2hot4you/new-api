# 隐藏 Grok 视频不支持元数据设计

## 背景

Molii 的通用视频预览弹框目前固定展示“尺寸”和“帧率”。Grok 视频接口不提供这两个参数，因此 Grok 任务中只能显示 `-`，既没有信息价值，也容易让用户误以为数据缺失或请求异常。

## 方案

采用平台级最小条件渲染：当任务平台为 Molii Grok（平台 `62`）时，不渲染“尺寸”和“帧率”两个详情项；其他视频平台继续沿用当前展示。

- Grok 视频保留：任务 ID、分辨率、宽高比、时长、参考视频、模型、生成时间和生成耗时。
- Grok 视频隐藏：尺寸、帧率。
- Seedance（平台 `61`）及其他视频平台不改变。
- 不修改任务数据、后端接口、数据库或签名视频代理。

为避免 JSX 中重复写平台判断，在视频预览模块中提供一个小型纯函数，表达平台是否支持展示尺寸和帧率；弹框通过该函数条件渲染两个详情项。

## 测试与验收

- 先写失败测试，确认平台 `62` 不展示技术元数据项。
- 确认平台 `61` 和普通视频平台仍展示尺寸及帧率。
- 运行 usage-logs 测试、TypeScript、格式检查、前端构建和 Go 测试。
- 重建本地常驻后端后，使用已有 Grok 视频任务打开预览弹框，确认“尺寸”和“帧率”消失，视频仍可播放且浏览器控制台无错误。

## 非目标

- 不删除翻译词条，因为 Seedance 等其他平台仍使用这些文案。
- 不改变列表中的分辨率、宽高比、时长和参考素材标签。
- 不推断 Grok 视频的尺寸或帧率。
