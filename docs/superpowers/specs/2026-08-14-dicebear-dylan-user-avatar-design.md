# Molii DiceBear Dylan 当前用户头像设计

## 目标与范围

将当前用户名首字头像替换为 DiceBear Dylan 风格头像，覆盖顶部账户菜单、个人资料页和移动端侧栏。使用日志、任务日志及管理列表中的用户标识保持不变。

同时修复首页搜索建议与后续操作按钮的层叠问题。`http://127.0.0.1:3000` 继续由 Go 后端代理前端开发服务，作为用户使用的本地开发入口。

## 头像生成

新增统一 `UserAvatar` 组件。组件接收用户 ID、显示名称及尺寸样式，通过 DiceBear 10.x Dylan HTTP API 生成 SVG：

```text
https://api.dicebear.com/10.x/dylan/svg?seed=molii-user-{id}
```

种子只使用内部数字用户 ID，不发送用户名、邮箱或其他个人资料。相同用户在各页面和会话中获得相同头像。SVG 加载失败时，继续显示现有首字回退，确保离线或第三方服务异常不会导致空白头像。

组件保持现有 `Avatar` 外观和尺寸 API，不增加数据库字段，不改认证响应，不引入头像编辑或上传功能。

## 接入点

- `ProfileDropdown`：触发按钮和下拉菜单头部使用同一 Dylan 头像。
- `ProfileHeader`：大尺寸资料头像使用同一用户 ID 种子。
- `MobileUserProfile`：删除硬编码 `/avatars/01.png`，改用统一组件。
- 日志与消息组件不变。

## 搜索层级修复

首页搜索容器的入场动画会创建独立层叠上下文，而其后的 CTA 容器在 DOM 顺序上后绘制，导致 CTA 覆盖绝对定位的搜索建议。给搜索动画容器设置明确的相对定位和更高层级，使建议列表始终位于 CTA 上方。保留现有键盘交互、定位和搜索提交行为。

## 测试与验收

- 单元测试验证用户 ID 稳定映射为 Dylan URL，且不会把名称或邮箱写入 URL。
- 组件测试验证 AvatarImage 与首字回退同时存在。
- 首页测试验证搜索容器具有高于 CTA 的层级契约。
- 完整前端测试、类型检查、格式和静态检查通过。
- 在 `127.0.0.1:3000` 实测搜索建议不再被按钮覆盖，并确认顶部、资料页及移动端头像一致。
