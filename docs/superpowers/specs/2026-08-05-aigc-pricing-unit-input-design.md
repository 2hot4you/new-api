# Molii AIGC 价格单位输入框设计

## 目标

统一 Seedance 2.0 与 Grok Imagine 价格表单的单位展示：计费单位位于输入框内部右侧，中文界面显示中文字段标题、说明和单位，现有保存与计费逻辑保持不变。

## 方案

- 新增一个计费页内部使用的 `PricingUnitInput` 展示组件，组合现有 `InputGroup`、`InputGroupInput` 和右侧 `InputGroupAddon`。
- Seedance 与 Grok 两个价格表单继续由 React Hook Form 管理数值，仅把原来的普通 `Input` 替换为 `PricingUnitInput`。
- Seedance 字段下方保留“是否包含参考视频”的说明，移除说明末尾的单位文本。
- Grok 当前没有独立字段说明，因此移除输入框下方仅用于显示单位的文本。
- 单位使用语义化 i18n 键：每张、每秒、每千次调用、每张生成完成的图片、每百万 Token。
- Grok 的字段标题和页面说明补齐简体中文与繁体中文；其他语言保留英文 fallback。

## 行为约束

- 输入框类型、最小值、步进精度、值变更、失焦与 ref 行为保持不变。
- 单位是只读后缀，不参与表单提交，也不遮挡数值输入。
- 不调整标签页、保存按钮、配置键或后端 API。

## 验证

- 组件测试验证单位位于输入框所属的 `InputGroup` 最右侧。
- i18n 测试验证简体中文单位及 Grok 字段文案。
- 运行受影响测试、TypeScript 类型检查、格式检查、lint 和前端生产构建。
- 在本地后台服务中检查两个标签页的中文展示。
