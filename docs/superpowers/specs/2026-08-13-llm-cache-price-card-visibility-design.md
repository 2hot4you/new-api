# LLM 概览页缓存价格卡片设计

## 目标

提升模型详情“概览”页中缓存输入价格的可见性，使其与输入、输出价格具有一致的视觉层级。

## 基础价格布局

- 输入、输出、缓存输入使用三张同尺寸、同样式的价格卡片。
- 桌面与模型详情抽屉宽度下使用三列布局，窄屏自动换行。
- 标签、价格和 Token 单位沿用现有格式，不修改金额计算。
- 没有缓存价格的模型只显示输入和输出，不制造空卡片。

## 动态分档价格

- 动态表达式中的输入、输出和缓存读取同样进入主要价格卡片区。
- 缓存写入、缓存写入 1 小时、图片和音频等其他价格继续放在下方次级价格区域。
- 动态分档表和按分组定价表不变。

## 保持不变

- 不修改价格、倍率、币种或 Token 单位切换。
- 不修改模型卡片、性能和 API 标签页。
- 不修改后端接口或计费逻辑。

## 测试

- 固定 Token 模型的输入、输出、缓存输入位于同一主要价格网格。
- 无缓存价格时主要网格仅包含输入和输出。
- 动态分档模型的缓存读取进入主要网格，其他次级价格仍留在次级区域。
- 主要网格具备三列响应式布局，现有定价测试和类型检查通过。
