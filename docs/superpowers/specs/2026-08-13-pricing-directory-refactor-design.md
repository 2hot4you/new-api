# Molii 模型广场高密度目录重构设计

日期：2026-08-13

## 背景

当前模型广场采用大幅首屏、独立圆角卡片和按厂商分组的展示方式。随着文本、图片和视频模型增加，这种结构占用空间较大，横向比较效率较低。新的页面参考 ZenMux 模型目录的信息架构，重构为高密度、细边框、表格式目录，并将模型详情从右侧抽屉迁移到既有独立路由。

本设计只借鉴信息架构与页面密度。Molii 继续使用自己的品牌、公共导航、字体、颜色语义、真实模型元数据和计费数据，不复制第三方品牌元素，也不展示没有可靠数据来源的指标。

## 目标

- 提升一屏可见模型数量和横向比较效率。
- 将筛选、搜索、分类和排序整合为稳定的模型发现流程。
- 默认按模型发布时间从新到旧展示。
- 将价格、能力、性能和 API 内容集中到可连续阅读的独立详情页。
- 保持所有展示字段来自 `/api/pricing`、模型元数据和真实性能接口。

## 非目标

- 不修改模型计费逻辑、渠道逻辑或后端 API 契约。
- 不新增调用量、缓存命中率、供应商数量等当前没有可靠来源的数据。
- 不复制 ZenMux 的 Logo、文案、广告、优惠、免费标签或第三方视觉资产。
- 不打包生产资源，不新增部署配置。
- 不保留按厂商分组的模型区块。

## 方案选择

采用高还原度的目录方案：细边框、连续网格、固定筛选栏、高密度模型单元和独立详情页。相比保留 Molii 现有圆角卡片的混合方案，该方案更接近目标参考页，也更适合持续扩充模型目录。

## 列表页结构

### 页面骨架

- 保留 Molii 现有公共顶部导航。
- 移除当前渐变背景、居中大标题、说明段落和大型搜索框。
- 桌面端使用固定左侧筛选栏和右侧内容区。
- 平板端模型目录为两列；移动端为单列，筛选栏收进抽屉。
- 右侧内容区依次展示标题与总数、动态模型分类、紧凑工具栏和模型目录。

### 动态模型分类

分类根据模型的输出能力与端点类型动态生成。首期包括：

- 全部
- 文本
- 图片
- 视频

数量为零的分类不显示。未来增加音频、嵌入、重排序等模型后，分类可由同一规则自动出现。每个分类显示当前数量，并与其他筛选条件组合生效。

### 筛选栏

筛选项均由当前模型数据动态生成：

- 输入类型：文本、图片、文件、音频、视频。
- 上下文长度：根据已有上下文元数据形成区间选项。
- 厂商：显示厂商 Logo、名称和模型数量；只用于筛选，不用于列表分组。
- 能力：推理、工具调用、结构化输出、流式输出、图片生成、视频生成等。
- 协议：Chat Completions、Responses、图片、视频、Embeddings 等。
- 计费类型：按量计费、按次计费、动态分档。
- 分组与标签：保留现有能力，放在筛选栏下部。

筛选器只显示有实际匹配模型的选项。桌面筛选栏随页面滚动保持可见，移动端通过工具栏按钮打开抽屉。

### 工具栏与排序

工具栏包含：

- 紧凑搜索框。
- 标准价格 / 充值价格切换。
- 排序菜单。
- 移动端筛选入口和活动筛选数量。

默认排序为“最新发布”：

1. 有 `release_date` 的模型按日期降序。
2. 日期相同则按模型 ID 升序，保证稳定结果。
3. 没有发布日期的模型排在所有有日期模型之后，再按模型 ID 升序。

其他排序保留名称、价格从低到高、价格从高到低。不提供没有正式业务字段支撑的折扣、免费筛选。

## 模型目录单元

模型列表不再按厂商分段，也不再使用互相分离的圆角悬浮卡片。模型单元通过细边框组成连续的三列网格，桌面同一行保持一致高度。

每个模型单元依次展示：

1. 厂商 Logo、模型显示名称、模型 ID 和复制按钮。
2. 两至三行模型简介。
3. 输入和输出模态图标。
4. 紧凑价格摘要。
5. 上下文、最大输出和核心能力。
6. 发布日期、端点协议和真实运行状态。

### 价格摘要

- LLM：展示输入、输出和存在时的缓存单价。
- Grok、Seedance 等复杂价格：展示“分档计费”和可计算的最低起始价格。
- 完整价格矩阵不在列表重复展示，统一放入独立详情页。
- 单位统一为 `¥ / 1,000,000 Token`、`¥ / 张`、`¥ / 秒`。

### 数据缺失

- 只显示存在且通过元数据接口返回的能力、模态、上下文、最大输出和发布日期。
- 性能数据存在时显示成功率、延迟或吞吐；不存在时显示明确的“暂无数据”。
- 不用占位数字或模拟数据填充调用量、缓存命中率、供应商数量。

### 交互

- 整个模型单元可点击，进入 `/pricing/{modelId}`。
- 复制按钮阻止点击冒泡，仅复制模型 ID。
- 移除列表中的独立“详情”按钮和右侧详情抽屉。
- 键盘用户可聚焦模型单元并通过 Enter 打开详情。

## 独立详情页

现有 `/pricing/{modelId}` 路由继续作为唯一模型详情入口，但页面从标签切换式布局改成连续阅读布局。

### 首屏

- 返回模型目录。
- 厂商 Logo、模型名称、模型 ID、状态和发布日期。
- 模型简介、输入输出模态和复制模型 ID。
- “查看 API 请求示例”按钮。
- 对实际支持当前 Playground 的文本模型显示“在 Playground 中使用”；其他模型不显示无效入口。

### 页面锚点

页面提供紧凑锚点导航：

- 定价
- 能力
- 性能
- API

锚点只负责页面内滚动，不隐藏内容。移动端允许横向滚动或收敛为紧凑下拉。

### 定价区

- LLM：输入、输出、缓存价格和按分组价格。
- Grok、Seedance：完整分辨率、输入类型、单位和计费公式表。
- 继续复用现有动态计费解析与价格展示逻辑。

### 能力区

展示上下文长度、最大输出、知识截止时间、输入输出模态和能力标签。只展示后端元数据中存在的字段，并保留元数据来源与最近验证时间。

### 性能区

继续使用 Molii 的真实成功率、延迟、吞吐和趋势数据。没有有效样本时显示空状态，不回退到模拟指标。

### API 区

继续复用现有参数表、请求 JSON、curl 示例、错误说明和模型特有参数。页面结构调整不得改变 API 示例的真实请求格式。

### 相关模型

页面底部展示同厂商的其他模型，排除当前模型，并按发布日期从新到旧排序。缺少日期的模型放在最后。

## 数据与状态

- 模型、厂商、价格、能力和发布日期继续来自现有 `usePricingData` 数据链。
- 性能继续来自性能摘要与详情接口。
- 筛选状态继续使用现有路由查询参数，以便列表与详情之间返回时保留搜索和筛选上下文。
- 新增分类、模态、能力和上下文筛选状态时同步扩展 `/pricing` 与 `/pricing/{modelId}` 的查询参数 schema。
- 不增加新的浏览器持久化数据源。

## 响应式与可访问性

- 大屏三列、中屏双列、小屏单列。
- 固定筛选栏不能遮挡公共导航，内容区不产生横向溢出。
- 模型单元、分类和筛选项都有可见焦点状态、语义化按钮和可读标签。
- 图标同时提供文本或辅助技术标签，颜色不是唯一的信息载体。
- 长模型 ID、长描述和复杂价格在小屏正确截断或换行。

## 测试与本地验收

- 排序测试：日期降序、相同日期稳定顺序、无日期置后。
- 分类测试：类型识别、零数量隐藏、组合筛选。
- 筛选测试：厂商、输入模态、上下文、能力、协议、计费类型组合。
- 模型单元测试：真实字段、缺失字段、复杂价格摘要、复制与跳转。
- 详情页测试：连续章节、锚点、价格矩阵、性能空状态、API 示例和相关模型。
- 响应式布局契约测试：三列、双列、单列和移动筛选入口。
- 运行前端定向测试、完整前端测试、类型检查、格式和差异检查。
- 只在本地开发环境运行并通过浏览器检查 `/pricing` 与若干不同类型详情页，不执行生产构建。

## 验收标准

- 列表页不再出现厂商分组外框或详情抽屉。
- 默认顺序与模型发布日期一致，无日期模型稳定置后。
- 模型目录在桌面呈现连续三列细边框布局。
- 所有筛选项和模型字段均来自真实接口数据。
- 文本、图片、视频模型都能进入独立详情页，并看到对应的真实价格、能力、性能与 API 内容。
- 返回列表后保留原有搜索和筛选上下文。
