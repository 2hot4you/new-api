# 产品报价及计算器设计

## 范围

在超级管理员后台增加独立页面 `/product-quotation`，导航位于 Task Plugins 与 System Settings 之间。页面只读取现有 `/api/pricing` 和 `/api/status` 数据，不修改计费配置，不增加数据库表，不部署生产。

## 权限边界

页面位于 `/_authenticated` 下，并在自己的 `beforeLoad` 中精确要求 `ROLE.SUPER_ADMIN`，非超级管理员跳转 `/403`。导航项同时设置 `requiredRole: ROLE.SUPER_ADMIN`。`/api/pricing` 继续保持模型广场现有公开行为；首版不新增后端接口，因此不存在新的服务端写入或导出权限面。

## 数据来源与映射

- 复用 `usePricingData()` 和 React Query 的 `['pricing']` 缓存。
- provider 使用 `PricingModel.vendor_id -> PricingData.vendors[].id` 映射；模型 ID 使用 `model_name`。
- 报价快照记录 `pricing_version`、浏览器成功获取时间、价格基准、选定用户分组、分组倍率和币种。
- 价格基准必须显式选择：`原始模型价（1x）` 或某个可用用户分组。不得调用模型广场“未选择时取最低分组倍率”的默认策略。
- 选择具体分组后，不在该分组可用的模型保留用户选择但标记不可用并阻止导出，避免静默丢失草稿。

## 价格归一化

报价内部使用结构化数值，不从格式化字符串反解析。每个价格项保存原价、报价、币种、单位、条件、来源类型和可计算状态。

- 固定 Token：输入价为 `model_ratio * 2`，输出、缓存写入/读取、图片输入、音频输入/输出继续使用现有倍率字段，默认单位为每 1M Token。
- 按次：使用 `model_price`，单位为每次请求；明确的 0 是合法免费价格，缺失值才是未配置。
- 动态/阶梯：复用现有 billing expression 解析器，完整展开所有 tier、价格维度与 request/time 条件。无法结构化解析时保留原始条件并标记“待确认”。
- Task usage：保留 base charge、second/count/token/credit 单位、enum 条件、所有 tier 和示例语义。
- Seedance 视频：展开所有分辨率以及包含/不包含视频输入价格，并保留 FPS、extra frames 与 Token 公式信息。
- Grok 图片/视频：展开每个质量/分辨率输出价格及图片/视频输入价格。
- `billing_currency === 'CNY'`、`video_pricing` 和 `molii_grok_pricing` 视为直接人民币；其他价格默认 USD。
- 价格基准的分组倍率最多应用一次，报价折扣最多应用一次；报价折扣不写回系统配置。

## 折扣与倍率计算器

全局折扣和 provider 覆盖都使用中文“折”，有效范围为 `0 < 折扣 <= 10`，provider 有有效覆盖时优先。报价为 `基准原价 × 折扣 / 10`。

独立倍率计算器使用：

```text
分组倍率 = 实际汇率 × (折扣 / 10) ÷ 系统固定汇率
```

例如实际汇率 6.8、5 折、固定汇率 7，结果为 `0.4857x`。输入必须为有限正数；结果可复制，但不会自动修改任何系统配置，也不会再次套用于报价价格。

## 草稿与刷新

草稿只保存用户输入、模型 ID 选择和 provider 覆盖，使用版本化 Zod schema 写入 namespaced localStorage。读取损坏、过期或超大草稿时安全回退。成功刷新价格只更新价格数据和获取时间，不清空草稿；已不存在的模型 ID 标记为不可用。

## 界面

桌面端为左侧编辑、右侧 sticky 纸张预览，小屏幕纵向堆叠。编辑区依次包括倍率计算器、报价信息、价格基准、模型选择和 provider 折扣/备注。模型支持搜索、全选、整组选择和单项选择。预览按 provider 分区，每项展示模型 ID、原价、折扣后报价、币种、单位和条件；不同单位不汇总总金额。

页面处理加载、失败与重试、空价格数据、未选模型、无效折扣/汇率、分组不可用和动态待确认状态。模型 ID 支持复制反馈。

## 离线 HTML

预览与导出消费同一份不可变报价快照。导出文件包含全部选中模型、价格维度、provider 备注、报价人、报价日期、币种、价格基准、价格版本与获取时间。

HTML 使用内嵌 CSS、无脚本、无外链、无表单，包含 UTF-8、no-referrer 和离线 CSP；所有用户输入与接口文本逐字段 HTML 转义。A4 打印样式避免 provider/模型块跨页和宽表截断。文件名为净化后的 `<报价标题>-<YYYY-MM-DD>.html`。无模型、价格加载失败、输入无效或所选模型在价格基准下不可用时阻止导出。

## 验证

单元测试覆盖折扣优先级、合法零价、小额价格、全部价格类型、动态降级、倍率公式、草稿恢复、HTML 注入与文件名。组件测试覆盖搜索、全选/整组选择、刷新保留草稿、禁用导出、复制反馈、加载/错误/空状态和响应式布局契约。路由测试覆盖超级管理员守卫和导航顺序。最终运行定向测试、类型检查、涉及文件 lint、格式、i18n 检查和生产构建，并在本地页面与导出文件上做视觉检查。
