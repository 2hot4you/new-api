# Molii Grok AIGC Implementation Plan

> Execute each task test-first. Run the focused failing test before implementation, then the focused passing test after implementation.

**Goal:** Add an independent Molii Grok AIGC channel for fixed-price image generation and asynchronous video generation without exposing upstream provider details.

**Architecture:** Independent image and task adaptors plug into the existing relay. Small optional interfaces extend image error sanitization and task polling privacy/status handling only when implemented. Existing billing and VideoProxy are reused with channel-scoped HTTPS/content-type enforcement.

**Tech stack:** Go, Gin, GORM, relaykit DTOs, React/TypeScript, Semi UI, Bun, node:test.
