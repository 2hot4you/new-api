# 模型元数据自动同步实施计划

## 1. 外部目录契约与选择规则

- 新增 models.dev 响应 DTO、字段规范化和可信厂商选择函数。
- 先写表驱动测试，覆盖重复模型 ID、官方厂商优先、模态映射、能力映射以及 cost 忽略。

## 2. 数据库补空同步

- 新增外部目录同步服务，仅读取已启用模型。
- 在事务中重新读取并锁定每个 Model；尊重软删除、`sync_official=0` 与管理员非空字段。
- 只补空字段，更新后失效 `/api/pricing` 缓存。
- 测试管理员优先、禁用同步、未知厂商、重复执行和部分字段补齐。

## 3. 后台 worker 与渠道通知

- 实际进程启动 worker；渠道缓存刷新发送非阻塞通知。
- 增加周期、超时、响应体上限和 URL 配置。
- 测试 HTTP 状态、超大响应、去重通知和失败不修改数据库。

## 4. 配置与验证

- 更新 `.env.example`。
- 运行模型层定向测试、相关缓存/定价测试、Go 全量测试、vet、gofmt 和 diff 检查。
- 按要求只使用本地开发验证，不执行前端或文档生产构建。
