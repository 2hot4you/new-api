# 更新日志

这里记录面向开发者的文档和公开接口变化。除非条目明确说明，已有集成无需调整。

## 2026-08-10

### 文档站点

- 新增帮助中心：可查看常见排障步骤和联系支持前应准备的信息。
- 新增中文本地搜索。生产构建会生成搜索索引；本地验证请先构建再预览。
- 增加公开内容、密钥和内部链接检查，帮助避免把不适合用户文档的内容发布到站点。

### 开发者指南

- 补充 API 密钥、任务轮询、媒体输入、计费和个人平台操作说明。
- 视频与图像示例继续使用环境变量和安全占位符，不包含真实凭据。

## 阅读与升级建议

- 在更新请求代码前，先确认当前使用的路径、请求字段和响应字段与 [API 参考](/api-reference) 一致。
- 付费创建请求发生超时或网络中断时，不要立即重复提交；保存公开 Request ID 并按[错误与重试](/api-basics/errors-retries)的步骤处理。
- 如有疑问，请参阅[排障指南](./help/troubleshooting)或[联系支持](./help/contact-support)。
