# 排障指南

先记录问题发生时间、请求方法、HTTP 状态和公开 `X-Oneapi-Request-Id`。不要记录 API Key、`Authorization` 请求头、完整媒体签名 URL 或个人资料。

## 无法登录或打开个人页面

1. 确认使用注册时的邮箱和当前有效的密码。
2. 收不到验证或重置邮件时，检查垃圾邮件箱并稍后重试；不要反复提交同一操作。
3. 重置成功后使用新密码返回登录页。仍无法登录时，联系支持并说明页面提示和发生时间。

## API 返回 401、403 或 429

| 状态 | 先做什么 |
| --- | --- |
| 401 | 检查服务端是否提供了有效的个人 API Key，确认没有多余空格或错误环境变量。 |
| 403 | 确认该 Key 可使用当前模型；不要把完整 Key 发送给任何人。 |
| 429 | 降低请求频率。对于安全 GET，可遵循 `Retry-After`；付费 POST 不要自动重试。 |

更多处理边界见[错误与重试](/api-basics/errors-retries)。

## 创建任务后状态没有更新

1. 保存创建响应中的任务 ID。
2. 使用 GET 查询任务状态，不要重复提交创建请求。
3. 状态为 `queued` 或 `in_progress` 时，按响应的建议间隔或有界退避继续查询。
4. 状态为 `failed` 时，保留公开 Request ID 和公开错误码以便排查。

## 媒体输入或下载失败

- 确认 URL 可从调用环境访问，并符合当前模型支持的媒体类型和数量。
- Data URL、`asset://` 引用和远程 URL 的支持范围因模型而异；请查看[媒体输入](/api-basics/media-inputs)和对应模型页。
- 下载结果前先检查响应的 `Content-Type` 是否为预期媒体类型，再写入文件。

## 本地文档搜索没有结果

中文搜索索引由生产构建生成，开发模式不生成索引。依次运行：

```bash
bun run build
bun run preview
```

然后在 `http://127.0.0.1:3100` 使用导航栏搜索框。构建失败时，先运行 `bun run check` 查看公开内容、密钥或链接检查的具体报错。

## 仍未解决

整理可公开分享的现象、复现步骤、时间、HTTP 状态、任务 ID 和脱敏后的 Request ID，再查看[联系支持](./contact-support)。
