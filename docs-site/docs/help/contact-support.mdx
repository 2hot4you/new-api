# 联系支持

当文档和排障步骤不能解决问题时，请通过 Molii 产品内可见的支持入口提交反馈。为帮助定位问题，请提供足够的公开上下文，但不要发送任何凭据或私人内容。

## 建议提供的信息

- 问题发生的日期、时间和时区。
- 你执行的操作与最小复现步骤。
- 请求方法、路径、HTTP 状态和公开错误码。
- 任务 ID，以及仅包含允许字符并已截断的 `X-Oneapi-Request-Id`。
- 使用的公开模型 ID、输入类型和不含私人内容的简化示例。
- 浏览器、操作系统或 SDK 版本，以及你已尝试过的步骤。

## 不要发送的信息

- API Key、密码、验证码、会话信息或 `Authorization` 请求头。
- 完整媒体签名 URL、个人资料、账单信息或未脱敏截图。
- 整组响应头、完整请求日志或与问题无关的个人数据。

## 提交后

保留原始请求的本地安全记录，以便支持人员需要补充信息时核对。付费创建请求遇到超时或连接中断时，不要因等待回复而重复提交；请先按[错误与重试](/api-basics/errors-retries)的指导保留任务 ID 与公开 Request ID。

如果需要附图，请使用合成或已脱敏数据，并确认截图中没有密钥、个人信息或私人媒体内容。
