## 兼容协议与安全调用

使用环境变量 `MOLII_API_KEY`，不要把密钥写入代码或客户端。

### OpenAI Chat Completions

**[POST /v1/chat/completions](/api-reference/chat-completions)**

```bash
: "${MOLII_API_BASE_URL:?Set MOLII_API_BASE_URL first}"
: "${MOLII_API_KEY:?Set MOLII_API_KEY first}"

curl --fail-with-body --silent --show-error \
  --max-time 60 \
  --request POST \
  --url "${MOLII_API_BASE_URL%/}/v1/chat/completions" \
  --header "Authorization: Bearer $MOLII_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{"model":"grok-build-0.1","messages":[{"role":"user","content":"你好"}]}'
```

### OpenAI Responses

**[POST /v1/responses](/api-reference/responses)**

```bash
: "${MOLII_API_BASE_URL:?Set MOLII_API_BASE_URL first}"
: "${MOLII_API_KEY:?Set MOLII_API_KEY first}"

curl --fail-with-body --silent --show-error \
  --max-time 60 \
  --request POST \
  --url "${MOLII_API_BASE_URL%/}/v1/responses" \
  --header "Authorization: Bearer $MOLII_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{"model":"grok-build-0.1","input":"你好"}'
```
