# grok-imagine-image-2.0

用于提示词驱动的生成、编辑及视觉设计工作流的图像模型

- **模型 ID：** `grok-imagine-image-2.0`
- **Provider：** xAI
- **输入模态：** text、image
- **输出模态：** image
- **英文简介：** Image model for prompt-driven generation\, editing\, and visual design workflows
- **发布日期：** 2026-08-07
- **最大输入图片数：** 3
- **支持分辨率：** 1080p
- **支持宽高比：** 16\:9
- **输出格式：** url、b64\_json
- **参考输入模态：** image

## 能力

- image\_generation

## 支持参数

- quality

## 兼容协议与安全调用

使用环境变量 `MOLII_API_KEY`，不要把密钥写入代码或客户端。

### Images

**[POST /v1/images/generations](/api-reference/images)**

```bash
: "${MOLII_API_BASE_URL:?Set MOLII_API_BASE_URL first}"
: "${MOLII_API_KEY:?Set MOLII_API_KEY first}"

curl --fail-with-body --silent --show-error \
  --max-time 60 \
  --request POST \
  --url "${MOLII_API_BASE_URL%/}/v1/images/generations" \
  --header "Authorization: Bearer $MOLII_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{"model":"grok-imagine-image-2.0","prompt":"描述所需图片"}'
```
