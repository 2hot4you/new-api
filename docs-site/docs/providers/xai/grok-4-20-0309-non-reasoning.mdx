## 兼容协议与安全调用

使用环境变量 `MOLII_API_KEY`，不要把密钥写入代码或客户端。### OpenAI Chat Completions

**POST /v1/chat/completions**

```bash
curl -X POST "${MOLII_BASE_URL:-https://api.molii.co}/v1/chat/completions" \
  -H "Authorization: Bearer $MOLII_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"grok-4.20-0309-non-reasoning","messages":[{"role":"user","content":"你好"}]}'
```

### OpenAI Responses

**POST /v1/responses**

```bash
curl -X POST "${MOLII_BASE_URL:-https://api.molii.co}/v1/responses" \
  -H "Authorization: Bearer $MOLII_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"grok-4.20-0309-non-reasoning","input":"你好"}'
```
