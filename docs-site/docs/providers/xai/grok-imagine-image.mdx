# grok-imagine-image

支持文本生成图片与参考图编辑，提供 1K、2K 输出，生成速度更快。

- **模型 ID：** `grok-imagine-image`
- **Provider：** xAI
- **输入模态：** text、image
- **输出模态：** image

## 能力

- image\_generation
- image\_editing

## 支持参数

- 未声明

## 兼容协议与安全调用

使用环境变量 `MOLII_API_KEY`，不要把密钥写入代码或客户端。### Images

**POST /v1/images/generations**

```bash
curl -X POST "${MOLII_BASE_URL:-https://api.molii.co}/v1/images/generations" \
  -H "Authorization: Bearer $MOLII_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"grok-imagine-image","prompt":"描述所需图片"}'
```

具备图片编辑能力时，也可调用 **POST /v1/images/edits**。

```bash
curl -X POST "${MOLII_BASE_URL:-https://api.molii.co}/v1/images/edits" \
  -H "Authorization: Bearer $MOLII_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"grok-imagine-image","prompt":"描述需要的编辑"}'
```
