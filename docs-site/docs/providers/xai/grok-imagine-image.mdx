# grok-imagine-image

支持文本生成图片与参考图编辑，提供 1K、2K 输出，生成速度更快。

- **模型 ID：** `grok-imagine-image`
- **Provider：** xAI
- **输入模态：** text、image
- **输出模态：** image
- **发布日期：** 2026-08-05
- **最大输入图片数：** 3
- **支持分辨率：** 1k、2k
- **支持宽高比：** 1\:1、16\:9、9\:16、4\:3、3\:4、3\:2、2\:3、2\:1、1\:2、19.5\:9、9\:19.5、20\:9、9\:20、auto
- **输出格式：** url
- **参考输入模态：** image

## 能力

- image\_generation
- image\_editing

## 支持参数

- 未声明

## 兼容协议与安全调用

使用环境变量 `MOLII_API_KEY`，不要把密钥写入代码或客户端。

### Images

**[POST /v1/images/generations](/api-reference/images)**

```bash
: "${MOLII_API_BASE_URL:?Set MOLII_API_BASE_URL first}"
: "${MOLII_API_KEY:?Set MOLII_API_KEY first}"

curl --fail-with-body --silent --show-error \
  --max-time 60 \
  --request POST \
  --url "${MOLII_API_BASE_URL%/}/v1/images/generations" \
  --header "Authorization: Bearer $MOLII_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{"model":"grok-imagine-image","prompt":"描述所需图片"}'
```

具备图片编辑能力时，也可调用 **[POST /v1/images/edits](/api-reference/images)**。

```bash
: "${MOLII_API_BASE_URL:?Set MOLII_API_BASE_URL first}"
: "${MOLII_API_KEY:?Set MOLII_API_KEY first}"

curl --fail-with-body --silent --show-error \
  --max-time 60 \
  --request POST \
  --url "${MOLII_API_BASE_URL%/}/v1/images/edits" \
  --header "Authorization: Bearer $MOLII_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{"model":"grok-imagine-image","prompt":"描述需要的编辑","images":[{"url":"https://example.invalid/source.png"}]}'
```
