# grok-imagine-video

异步文生视频、图生视频与视频编辑模型，支持 480p、720p 输出。

- **模型 ID：** `grok-imagine-video`
- **Provider：** xAI
- **输入模态：** text、image、video
- **输出模态：** video
- **发布日期：** 2026-08-05
- **最大输入图片数：** 1
- **视频时长范围：** 1–15 秒
- **支持分辨率：** 480p、720p
- **支持宽高比：** 1\:1、16\:9、9\:16、4\:3、3\:4、3\:2、2\:3
- **输出格式：** url
- **参考输入模态：** image、video

## 能力

- video\_generation
- video\_editing

## 支持参数

- 未声明

## 兼容协议与安全调用

使用环境变量 `MOLII_API_KEY`，不要把密钥写入代码或客户端。

### OpenAI Video

**[POST /v1/videos](/api-reference/videos)**

```bash
: "${MOLII_API_BASE_URL:?Set MOLII_API_BASE_URL first}"
: "${MOLII_API_KEY:?Set MOLII_API_KEY first}"

curl --fail-with-body --silent --show-error \
  --max-time 60 \
  --request POST \
  --url "${MOLII_API_BASE_URL%/}/v1/videos" \
  --header "Authorization: Bearer $MOLII_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{"model":"grok-imagine-video","prompt":"描述所需视频"}'
```

创建视频是异步操作。保存创建响应中的任务 ID；下面的 GET 请求有单次超时且不自动重试。

```bash
TASK_ID='task_public_123'
```

**[GET /v1/videos/\{task_id\}](/api-reference/videos)**

```bash
: "${MOLII_API_BASE_URL:?Set MOLII_API_BASE_URL first}"
: "${MOLII_API_KEY:?Set MOLII_API_KEY first}"

curl --fail-with-body --silent --show-error \
  --max-time 30 \
  --max-redirs 0 \
  --request GET \
  --url "${MOLII_API_BASE_URL%/}/v1/videos/$TASK_ID" \
  --header "Authorization: Bearer $MOLII_API_KEY" \
  --header "Accept: application/json"
```

**[GET /v1/videos/\{task_id\}/content](/api-reference/videos)**

```bash
: "${MOLII_API_BASE_URL:?Set MOLII_API_BASE_URL first}"
: "${MOLII_API_KEY:?Set MOLII_API_KEY first}"

curl --fail-with-body --silent --show-error \
  --max-time 300 \
  --max-redirs 0 \
  --request GET \
  --url "${MOLII_API_BASE_URL%/}/v1/videos/$TASK_ID/content" \
  --header "Authorization: Bearer $MOLII_API_KEY" \
  --dump-header ./video-content.headers \
  --output ./video-content.bin \
  --header "Accept: video/*"
```

内容请求故意不使用 `--location`，不会把 Molii 凭据转发给重定向主机。检查响应头和内容类型后再保存结果，详见[视频 API](/api-reference/videos)。创建请求可能产生费用；网络结果不确定时不要重复提交 POST。

## 调用提示

同步接口在返回响应后完成。异步接口请保留任务 ID 并轮询结果；网络超时不表示请求未受理，提交前先查询任务，避免重复付费请求。
