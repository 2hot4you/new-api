# Claude Opus 4.7

Anthropic Opus 前一代，仍可用的强编码与视觉模型。

- **模型 ID：** `claude-opus-4-7`
- **Provider：** Anthropic
- **输入模态：** text、image
- **输出模态：** text
- **上下文长度：** 1000000

## 兼容协议与安全调用

使用环境变量 `MOLII_API_KEY`，不要把密钥写入代码或客户端。### Anthropic Messages

**POST /v1/messages**

```bash
curl -X POST "${MOLII_BASE_URL:-https://api.molii.co}/v1/messages" \
  -H "Authorization: Bearer $MOLII_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"claude-opus-4-7","max_tokens":256,"messages":[{"role":"user","content":"你好"}]}'
```

### OpenAI Chat Completions

**POST /v1/chat/completions**

```bash
curl -X POST "${MOLII_BASE_URL:-https://api.molii.co}/v1/chat/completions" \
  -H "Authorization: Bearer $MOLII_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"claude-opus-4-7","messages":[{"role":"user","content":"你好"}]}'
```
