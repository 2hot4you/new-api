## 兼容协议与安全调用

使用环境变量 `MOLII_API_KEY`，不要把密钥写入代码或客户端。

### Anthropic Messages

**[POST /v1/messages](/api-reference/anthropic-messages)**

```bash
: "${MOLII_API_BASE_URL:?Set MOLII_API_BASE_URL first}"
: "${MOLII_API_KEY:?Set MOLII_API_KEY first}"

curl --fail-with-body --silent --show-error \
  --max-time 60 \
  --request POST \
  --url "${MOLII_API_BASE_URL%/}/v1/messages" \
  --header "x-api-key: $MOLII_API_KEY" \
  --header "anthropic-version: 2023-06-01" \
  --header "Content-Type: application/json" \
  --data '{"model":"claude-fable-5","max_tokens":256,"messages":[{"role":"user","content":"你好"}]}'
```

### OpenAI Chat Completions

**[POST /v1/chat/completions](/api-reference/chat-completions)**

```bash
: "${MOLII_API_BASE_URL:?Set MOLII_API_BASE_URL first}"
: "${MOLII_API_KEY:?Set MOLII_API_KEY first}"

curl --fail-with-body --silent --show-error \
  --max-time 60 \
  --request POST \
  --url "${MOLII_API_BASE_URL%/}/v1/chat/completions" \
  --header "Authorization: Bearer $MOLII_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{"model":"claude-fable-5","messages":[{"role":"user","content":"你好"}]}'
```
