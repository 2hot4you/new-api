# Claude Haiku 4.5

Anthropic 最快最便宜 Haiku，适合高吞吐简单任务。

- **模型 ID：** `claude-haiku-4-5-20251001`
- **Provider：** Anthropic
- **输入模态：** text、image
- **输出模态：** text
- **上下文长度：** 200000
- **最大输出 Token：** 64000

## 兼容协议与安全调用

使用环境变量 `MOLII_API_KEY`，不要把密钥写入代码或客户端。### Anthropic Messages

**POST /v1/messages**

```bash
curl -X POST "${MOLII_BASE_URL:-https://api.molii.co}/v1/messages" \
  -H "Authorization: Bearer $MOLII_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"claude-haiku-4-5-20251001","max_tokens":256,"messages":[{"role":"user","content":"你好"}]}'
```

### OpenAI Chat Completions

**POST /v1/chat/completions**

```bash
curl -X POST "${MOLII_BASE_URL:-https://api.molii.co}/v1/chat/completions" \
  -H "Authorization: Bearer $MOLII_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"claude-haiku-4-5-20251001","messages":[{"role":"user","content":"你好"}]}'
```
