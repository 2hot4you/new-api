# Doubao Seedance 2.0 Fast

Seedance 2.0 加速版，支持文本、图片和视频参考及同步音频生成，面向低延迟创意迭代，支持 480p/720p。

- **模型 ID：** `doubao-seedance-2-0-fast-260128`
- **Provider：** ByteDance
- **输入模态：** text、image、video、audio
- **输出模态：** video、audio
- **发布日期：** 2026-01-28
- **最大输入图片数：** 9
- **视频时长范围：** 4–15 秒
- **支持分辨率：** 480p、720p
- **支持宽高比：** 16\:9、4\:3、1\:1、3\:4、9\:16、21\:9、adaptive
- **输出格式：** url
- **参考输入模态：** image、video、audio

## 兼容协议与安全调用

使用环境变量 `MOLII_API_KEY`，不要把密钥写入代码或客户端。

### Seedance Video

**[POST /v1/videos](/api-reference/videos)**

```bash
: "${MOLII_API_BASE_URL:?Set MOLII_API_BASE_URL first}"
: "${MOLII_API_KEY:?Set MOLII_API_KEY first}"

curl --fail-with-body --silent --show-error \
  --max-time 60 \
  --request POST \
  --url "${MOLII_API_BASE_URL%/}/v1/videos" \
  --header "Authorization: Bearer $MOLII_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{"model":"doubao-seedance-2-0-fast-260128","content":[{"type":"text","text":"镜头缓慢向前推进，晨雾从山谷间流过"},{"type":"image_url","image_url":{"url":"https://example.invalid/first-frame.jpg"},"role":"first_frame"}],"generate_audio":true,"resolution":"720p","ratio":"16:9","duration":5,"watermark":false}'
```

创建视频是异步操作。付费 POST 只提交一次，并保存响应中的公共任务 ID：

```json
{
  "id": "task_public_123",
  "object": "video",
  "model": "doubao-seedance-2-0-fast-260128",
  "status": "queued",
  "progress": 0
}
```

```bash
TASK_ID='task_public_123'
```

**[GET /v1/videos/\{task_id\}](/api-reference/videos)**

```bash
: "${MOLII_API_BASE_URL:?Set MOLII_API_BASE_URL first}"
: "${MOLII_API_KEY:?Set MOLII_API_KEY first}"

curl --fail-with-body --silent --show-error \
  --max-time 30 \
  --max-redirs 0 \
  --request GET \
  --url "${MOLII_API_BASE_URL%/}/v1/videos/$TASK_ID" \
  --header "Authorization: Bearer $MOLII_API_KEY" \
  --header "Accept: application/json"
```

状态为 `queued` 或 `in_progress` 时继续有限轮询；`completed` 与 `failed` 为终态。

**[GET /v1/videos/\{task_id\}/content](/api-reference/videos)**

```bash
: "${MOLII_API_BASE_URL:?Set MOLII_API_BASE_URL first}"
: "${MOLII_API_KEY:?Set MOLII_API_KEY first}"

curl --fail-with-body --silent --show-error \
  --max-time 300 \
  --max-redirs 0 \
  --request GET \
  --url "${MOLII_API_BASE_URL%/}/v1/videos/$TASK_ID/content?download=1" \
  --header "Authorization: Bearer $MOLII_API_KEY" \
  --dump-header ./seedance-content.headers \
  --output ./seedance-result.mp4 \
  --header "Accept: video/*"
```

内容请求故意不使用 `--location`，不会把 Molii 凭据转发给其他主机。`download=1` 让 Molii 返回附件下载响应。

完整字段、组合限制和更多示例见 [Seedance API](/api-reference/seedance)、[多模态输入指南](/guides/seedance-multimodal)、[临时素材 API](/api-reference/assets) 与 [curl 完整流程](/examples/seedance-curl)。创建请求可能产生费用；网络结果不确定时不要重复提交 POST。

## 调用提示

同步接口在返回响应后完成。异步接口请保留任务 ID 并轮询结果；网络超时不表示请求未受理，提交前先查询任务，避免重复付费请求。
