# Qwen 3.7 Max

阿里通义千问上一代旗舰文本模型，强调 Agent、编程与长程自主执行。

- **模型 ID：** `qwen3.7-max`
- **Provider：** Alibaba
- **输入模态：** text
- **输出模态：** text
- **上下文长度：** 1000000
- **最大输出 Token：** 131072

使用环境变量 `MOLII_API_KEY`，不要把密钥写入代码或客户端。### OpenAI Chat Completions

**POST /v1/chat/completions**

```bash
curl -X POST "${MOLII_BASE_URL:-https://api.molii.co}/v1/chat/completions" \
```
