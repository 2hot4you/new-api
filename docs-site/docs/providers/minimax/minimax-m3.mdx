# MiniMax M3

MiniMax 前沿开源模型，原生多模态 + 1M 上下文 + 编码/Agent。

- **模型 ID：** `minimax-m3`
- **Provider：** MiniMax
- **输入模态：** text、image、video
- **输出模态：** text
- **上下文长度：** 1000000
- **最大输出 Token：** 512000

## 能力

- function\_calling
- streaming
- vision
- json\_mode
- structured\_output
- reasoning
- tools
- system\_prompt
- caching

## 兼容协议与安全调用

使用环境变量 `MOLII_API_KEY`，不要把密钥写入代码或客户端。### OpenAI Chat Completions

**POST /v1/chat/completions**

```bash
curl -X POST "${MOLII_BASE_URL:-https://api.molii.co}/v1/chat/completions" \
  -H "Authorization: Bearer $MOLII_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"minimax-m3","messages":[{"role":"user","content":"你好"}]}'
```
