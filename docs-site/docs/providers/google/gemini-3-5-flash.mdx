- **发布日期：** 2026-05-19
- **知识截止：** 2026-05

## 兼容协议与安全调用

使用环境变量 `MOLII_API_KEY`，不要把密钥写入代码或客户端。

### Gemini GenerateContent

**[POST /v1beta/models/gemini-3.5-flash:generateContent](/api-reference/gemini-generate-content)**

```bash
: "${MOLII_API_BASE_URL:?Set MOLII_API_BASE_URL first}"
: "${MOLII_API_KEY:?Set MOLII_API_KEY first}"

curl --fail-with-body --silent --show-error \
  --max-time 60 \
  --request POST \
  --url "${MOLII_API_BASE_URL%/}/v1beta/models/gemini-3.5-flash:generateContent" \
  --header "x-goog-api-key: $MOLII_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{"contents":[{"parts":[{"text":"你好"}]}]}'
```

### OpenAI Chat Completions

**[POST /v1/chat/completions](/api-reference/chat-completions)**

```bash
: "${MOLII_API_BASE_URL:?Set MOLII_API_BASE_URL first}"
: "${MOLII_API_KEY:?Set MOLII_API_KEY first}"

curl --fail-with-body --silent --show-error \
  --max-time 60 \
  --request POST \
  --url "${MOLII_API_BASE_URL%/}/v1/chat/completions" \
  --header "Authorization: Bearer $MOLII_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{"model":"gemini-3.5-flash","messages":[{"role":"user","content":"你好"}]}'
```
