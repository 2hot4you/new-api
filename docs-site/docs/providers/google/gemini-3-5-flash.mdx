# Gemini 3.5 Flash

Google 早期 Flash 基线，适合高吞吐日常任务。

- **模型 ID：** `gemini-3.5-flash`
- **Provider：** Google
- **输入模态：** text、image、audio、video、file
- **输出模态：** text
- **上下文长度：** 1048576
- **最大输出 Token：** 65536

## 兼容协议与安全调用

使用环境变量 `MOLII_API_KEY`，不要把密钥写入代码或客户端。### Gemini GenerateContent

**POST /v1beta/models/gemini-3.5-flash:generateContent**

```bash
curl -X POST "${MOLII_BASE_URL:-https://api.molii.co}/v1beta/models/gemini-3.5-flash:generateContent" \
  -H "Authorization: Bearer $MOLII_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"contents":[{"parts":[{"text":"你好"}]}]}'
```

### OpenAI Chat Completions

**POST /v1/chat/completions**

```bash
curl -X POST "${MOLII_BASE_URL:-https://api.molii.co}/v1/chat/completions" \
  -H "Authorization: Bearer $MOLII_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"gemini-3.5-flash","messages":[{"role":"user","content":"你好"}]}'
```
