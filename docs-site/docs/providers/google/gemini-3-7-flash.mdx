## 兼容协议与安全调用

使用环境变量 `MOLII_API_KEY`，不要把密钥写入代码或客户端。

### Gemini GenerateContent

**POST /v1beta/models/gemini-3.7-flash:generateContent**

```bash
curl --fail-with-body --silent --show-error \
  --max-time 60 \
  --request POST \
  --url "${MOLII_BASE_URL:-https://api.molii.co}/v1beta/models/gemini-3.7-flash:generateContent" \
  --header "x-goog-api-key: $MOLII_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{"contents":[{"parts":[{"text":"你好"}]}]}'
```

### OpenAI Chat Completions

**POST /v1/chat/completions**

```bash
curl --fail-with-body --silent --show-error \
  --max-time 60 \
  --request POST \
  --url "${MOLII_BASE_URL:-https://api.molii.co}/v1/chat/completions" \
  --header "Authorization: Bearer $MOLII_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{"model":"gemini-3.7-flash","messages":[{"role":"user","content":"你好"}]}'
```
