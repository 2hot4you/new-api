# 模型广场与 Playground

## 模型广场

打开 `/pricing` 查看“模型广场”。可按模型名、提供商、端点或标签搜索，并使用页面提供的筛选、排序和卡片/表格视图比较模型。选择模型可查看该模型的能力、价格和可用信息；没有匹配项时清除筛选或更换搜索词。

模型是否可用、价格展示方式和可选分组以页面实时数据为准。模型详情中没有显示的能力不应假定可用；价格或可用性加载失败时刷新后再确认。

## Playground

登录后打开 `/playground`。选择当前可用的分组和模型，在输入框写入消息并发送；生成过程中可停止，已有消息可按页面提供的操作重新生成、编辑或删除。需要清空会话时使用“清空”或等效操作。

Playground 目前仅支持 chat/对话。它不支持 Seedance 生成任务，也不支持 Grok 图片或视频生成；请不要把这类生成流程当作 Playground 功能。若 Playground 入口未显示或访问后回到看板，表示聊天模块当前未启用。

## 状态说明

| 状态 | 处理方式 |
| --- | --- |
| 成功 | 模型列表载入并收到对话回复后，可继续发送消息或管理当前会话。 |
| 空状态 | 没有可选模型、没有历史消息或搜索无结果时，检查分组、搜索条件或稍后刷新。 |
| 未启用 | 未显示 Playground、分组、模型或参数面板时，该项功能当前不可用。 |
| 已过期 | 临时会话或登录状态失效后，重新登录并重新发送尚未完成的内容。 |
| 错误 | 请求失败时阅读消息旁提示；不要把同一条可能计费的请求连续重复发送。 |
