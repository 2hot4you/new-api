# 钱包与账单

在 `/wallet` 查看钱包信息。页面显示的币种、充值方式、套餐、兑换或转赠选项由当前站点配置决定。

## 充值与兑换

1. 查看余额和可用的充值金额或套餐。
2. 选择页面显示的支付方式，输入金额或选择预设金额。
3. 在确认窗口核对金额、币种和支付方式后再继续。
4. 完成外部支付后回到钱包刷新余额。

如果页面提供兑换码，可在兑换区域输入并提交。转赠、推广奖励或订阅套餐只有在对应卡片出现时才可使用。不要在不受信任的页面输入支付信息，也不要因付款页面暂时未跳转就重复发起付款。

## 订单历史

选择“订单历史”或通过 `/wallet?show_history=true` 打开历史记录。这里用于查看充值交易记录和支付历史，并可按订单号搜索。余额没有立即刷新时，稍后刷新并以订单记录和支付渠道的最终结果为准。

## 状态说明

| 状态 | 处理方式 |
| --- | --- |
| 成功 | 支付完成后刷新钱包，并在订单历史中核对充值交易。 |
| 空状态 | 没有充值订单或可选套餐时，表示当前没有可展示项目。 |
| 未启用 | 未显示某种支付、兑换、转赠、订阅或奖励卡片时，该功能当前不可用。 |
| 已过期 | 支付确认窗口、兑换码或支付链接已过期时，关闭后从钱包重新开始。 |
| 错误 | 支付失败时不要重复发起订单；先查看支付渠道状态和订单历史，再决定是否重新操作。 |
