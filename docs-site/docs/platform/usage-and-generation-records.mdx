# 使用与生成记录

打开 `/usage-logs` 查看记录。默认页会进入“通用日志”；页面可用时，可切换到“图像生成”或“视频生成”。

## 查找记录

使用页面提供的时间范围、模型、Key、请求 ID、状态或关键词筛选。图片和视频生成页还可显示相应来源选项。打开一条记录可查看详情、提示词、失败原因、媒体预览或账单信息（页面显示什么取决于该记录类型）。

记录为空时，先清除筛选并扩大时间范围。新提交的生成任务可能需要等待状态更新；失败记录通常会给出可阅读的原因。不要仅根据浏览器重试就假定请求没有创建，先在记录中确认。

## 成本与媒体

记录中的成本、状态和耗时以该条目的页面详情为准。预览打不开时，先确认任务是否成功和链接是否仍有效；如需保留结果，请在结果仍可访问时按当前页面提供的方式处理。

## 状态说明

| 状态 | 处理方式 |
| --- | --- |
| 成功 | 打开详情核对模型、时间、成本和结果预览。 |
| 空状态 | 清除筛选、调整时间范围，或等待刚完成的请求同步。 |
| 未启用 | 未显示图片或视频生成分区时，该记录视图当前不可用。 |
| 已过期 | 临时预览或结果链接失效后，记录仍可用于核对；需要结果时使用仍有效的保存方式。 |
| 错误 | 查看失败原因和请求 ID，修正输入后再创建新请求。 |
