# 注册、登录与找回密码

普通用户从 `/sign-up` 注册、从 `/sign-in` 登录。已经登录时访问这些页面会回到看板。

## 注册

1. 打开 `/sign-up`，填写用户名、邮箱和密码。
2. 如果页面显示邮箱验证码，先发送并填写验证码；验证码过期或发送失败时，按页面提示重新发送。
3. 如页面显示服务条款或隐私政策，勾选同意项。
4. 若页面启用了人机验证，完成验证后选择“注册”。

注册成功后会进入登录后的页面。若用户名或邮箱已被使用、验证码不正确、验证码已过期，或人机验证未完成，请修正提示的项目后再试。注册入口或第三方登录方式是否显示，取决于当前站点配置；未启用时不会显示相应按钮。

## 登录与验证

在 `/sign-in` 输入用户名和密码，然后选择“登录”。如果账户开启了双因素验证，登录成功后还需要在 `/otp` 输入验证码。验证码错误、过期或当前登录流程已失效时，请回到登录页重新开始。

页面可能按配置提供 Passkey、OAuth 或微信登录。只有出现相应按钮时才可使用；设备或浏览器不支持 Passkey 时，请改用密码或其他已显示的方法。登录失败时不要反复猜测密码，确认账号信息或使用找回密码。

## 找回密码

1. 在登录页选择“忘记密码”，或打开 `/forgot-password`。
2. 填写已绑定的邮箱并发送重置邮件。
3. 通过邮件中的链接打开 `/reset`，设置新密码。
4. 使用新密码回到 `/sign-in` 登录。

邮件未到达时，先检查垃圾邮件箱并确认邮箱拼写；重置链接已过期时，重新发起一次找回密码。为保护账户安全，不要把验证码、重置链接或密码提供给他人。

## 状态说明

| 状态 | 处理方式 |
| --- | --- |
| 成功 | 注册或登录完成后进入普通用户页面；需要双因素验证时继续完成验证。 |
| 空状态 | 未填写必填项时，先补全用户名、邮箱或密码。 |
| 未启用 | 未显示注册、Passkey、OAuth、微信或邮箱验证入口，表示该功能当前不可用。 |
| 已过期 | 邮箱验证码、重置链接或双因素登录流程失效后，重新发送或重新登录。 |
| 错误 | 阅读表单旁或页面提示；网络错误时确认网络后再提交一次。 |
