# 看板

登录后打开 `/dashboard`，页面默认进入“概览”。可用的页面分区会随账号权限和站点配置变化。

## 查看概览

“概览”集中展示公告、API 信息、常见问题、汇总卡片及可用性信息。先查看公告和 API 信息，再根据汇总卡片了解当前使用情况。某些面板在服务没有公开数据时会显示空状态，而不是零用量。

## 查看模型调用分析与分流

侧边分区可显示“模型调用分析”和“分流”。在“模型调用分析”中按页面提供的时间范围或模型筛选条件查看调用分布、趋势和性能概览；在“分流”中查看可用的图表。筛选后没有数据时，清除筛选、扩大时间范围，或等待新的调用记录出现。

> 分区是否显示以当前看板为准。没有显示的分区代表它当前未启用或不适用于你的账户。

## 状态说明

| 状态 | 处理方式 |
| --- | --- |
| 成功 | 图表和汇总卡片载入后，按时间范围和筛选条件阅读数据。 |
| 空状态 | 没有调用或公告时，调整筛选、稍后刷新，或先完成一次正常调用。 |
| 未启用 | 未出现某个分区或面板时，不代表数据丢失；该功能当前未开放。 |
| 已过期 | 时间范围外的数据不会出现在当前图表中；重新选择包含目标日期的范围。 |
| 错误 | 面板加载失败时刷新页面；持续失败则记录提示信息联系支持。 |
