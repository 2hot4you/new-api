# 临时素材

在 `/temporary-assets` 管理当前账户的图片、视频和音频临时素材。素材仅用于短期处理；不要把它当作永久文件库。

## 创建和查看

页面固定提供“上传本地文件”和“通过 URL 添加”两个页签。若本地上传未启用，上传区域仍会显示但处于禁用状态；此时“通过 URL 添加”仍可使用，可填写名称、类型和可公开访问的媒体 URL。创建后在列表中查看预览、类型、状态和到期信息，并用类型、ID 或时间范围筛选。

处理中素材尚不能稳定引用。处理成功后再复制或使用页面提供的素材引用；来源不可访问、格式不支持或处理失败时，修正来源后创建新素材。接近过期的素材应及时替换。

## 更新来源和删除

对可编辑的素材可更新来源地址；确认内容无误后保存。删除单个或选中的素材前确认没有任务仍在引用它。删除或到期后，原有临时引用不能用于新的请求。

> 本地上传是否可用以控件状态为准。上传区域禁用时可切换到 URL 页签；不要绕过页面限制上传敏感或无权使用的媒体。

## 状态说明

| 状态 | 处理方式 |
| --- | --- |
| 成功 | 素材处理完成并可预览后，再用于允许的工作流。 |
| 空状态 | 没有素材时，使用当前页面提供的创建方式添加一个。 |
| 未启用 | 本地上传未启用时，上传控件保留但不可点击；URL 创建仍可使用。 |
| 已过期 | 已过期素材不可继续引用；使用原始媒体重新创建。 |
| 错误 | 预览或处理错误时检查格式、大小、来源可访问性，然后新建或重试。 |
