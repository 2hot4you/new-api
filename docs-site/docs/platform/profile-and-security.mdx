# 个人资料与安全

打开 `/profile` 管理你的个人资料与安全设置。页面可显示的卡片受账号状态、浏览器能力和站点配置影响。

## 个人资料和登录方式

在个人资料卡更新允许修改的名称、邮箱或其他账户信息。若页面提供账号绑定，可按提示绑定或解除邮箱、Telegram、微信等登录方式。修改密码时输入当前密码和新密码；完成后用新密码重新确认登录。

语言偏好和侧边栏模块设置会在对应卡片显示时可用。更新后检查页面提示；未出现的设置不应视作已启用。

## 保护账户

- 在“登录会话”中检查设备和最近登录时间，发现陌生设备时立即结束该会话并修改密码。
- 如果页面显示 Passkey，可在支持的设备和浏览器上添加；不支持时继续使用密码和双因素验证。
- 如果页面显示双因素验证，按引导保存恢复码并放在安全位置。不要只把恢复码保存在同一台设备上。
- 删除账户是不可逆的高风险操作；确认页面提示并先备份自己需要保留的信息。

签到、通知、侧边栏设置、Passkey 和双因素验证都可能因配置而未启用。登录验证方式发生变化后，保留至少一种可用的登录或恢复方式，避免把自己锁在账户外。

## 状态说明

| 状态 | 处理方式 |
| --- | --- |
| 成功 | 保存后检查页面提示，并用新的登录方式或安全设置完成一次确认。 |
| 空状态 | 没有登录会话或绑定方式时，按需要添加可用的安全方式。 |
| 未启用 | 未显示签到、绑定、Passkey、双因素验证或侧边栏设置时，该功能当前不可用。 |
| 已过期 | 安全验证链接、验证码或恢复流程失效后，从登录页重新开始。 |
| 错误 | 更新失败时保留当前页面，不要重复提交；阅读错误提示后重新验证输入。 |
