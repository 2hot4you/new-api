# API 密钥

在 `/keys` 打开“API 密钥”。每个 Key 只应授予一个应用或环境使用，以便出现问题时能单独停用。

## 创建 Key

1. 选择页面上的“创建 API 密钥”。
2. 填写名称、有效期、可用分组及模型限制；页面显示的字段以当前配置为准。
3. 保存后立即复制新 Key，并存入密码管理器或服务端密钥管理服务。

Key 明文通常只会在创建时显示一次。关闭提示后无法通过列表找回完整值；应新建一个 Key，而不是尝试从已遮罩的列表项恢复它。

## 管理已有 Key

在列表中可按状态、名称或 Key 片段筛选。打开某一项后可修改名称、有效期、分组或模型限制（若页面提供这些选项）。不再使用时先停用验证影响，再删除。批量操作只对当前选中的个人 Key 生效。

不要把 Key 放入浏览器前端代码、截图、提交记录或聊天消息。若怀疑泄露，立即停用或删除该 Key，创建替代 Key，并更新使用它的服务端配置。

## 状态说明

| 状态 | 处理方式 |
| --- | --- |
| 成功 | 新建后安全保存明文；编辑或状态变更后检查列表提示。 |
| 空状态 | 列表为空时创建第一个 Key；筛选为空时清除筛选条件。 |
| 未启用 | 某些分组、模型限制或批量操作未显示时，以当前页面可用功能为准。 |
| 已过期 | 已过期 Key 不能继续用于请求；创建新 Key 并更新调用方。 |
| 错误 | 保存失败时检查必填项、有效期和权限范围；不要重复创建多个相同用途的 Key。 |
