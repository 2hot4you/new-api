# 模型概览

Molii 当前公开 Seedance 2.0 和 Grok Imagine 模型。以下内容只描述普通用户可以通过 API Key 调用的模型，不包含渠道或管理配置。

| 模型 ID | 类型 | 主要能力 | 支持的分辨率 |
| --- | --- | --- | --- |
| `doubao-seedance-2-0-260128` | 视频 | 文本、多模态参考、音频与联网工具 | `480p`、`720p`、`1080p`、`4k` |
| `doubao-seedance-2-0-fast-260128` | 视频 | Seedance Fast 生成 | `480p`、`720p` |
| `grok-imagine-image` | 图片 | 图片生成与编辑 | `1k`、`2k` |
| `grok-imagine-image-quality` | 图片 | 高质量图片生成与编辑 | `1k`、`2k` |
| `grok-imagine-video` | 视频 | 文生视频、图生视频、视频编辑 | `480p`、`720p` |
| `grok-imagine-video-1.5` | 视频 | 图生视频 | `480p`、`720p`、`1080p` |

Fast 版不可使用 `1080p` 或 `4k`。如果请求需要这两个分辨率，请选择标准版。

Seedance 与 Grok 视频都通过 `POST /v1/videos` 创建异步任务。Grok 图片使用 `POST /v1/images/generations` 或 `POST /v1/images/edits` 同步返回结果。视频创建可能产生费用，网络结果不确定时不要自动重发 POST。
