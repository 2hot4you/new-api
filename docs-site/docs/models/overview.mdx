# 模型概览

Molii 当前提供两个 Seedance 2.0 视频模型。它们使用相同的异步视频接口和多模态 `content` 结构，主要差异是定位和可选分辨率。

| 模型 ID | 版本 | 支持的分辨率 |
| --- | --- | --- |
| `doubao-seedance-2-0-260128` | 标准版 | `480p`、`720p`、`1080p`、`4k` |
| `doubao-seedance-2-0-fast-260128` | Fast 版 | `480p`、`720p` |

Fast 版不可使用 `1080p` 或 `4k`。如果请求需要这两个分辨率，请选择标准版。

两个模型都通过 `POST /v1/videos` 创建异步任务。创建成功后保存响应中的公开 `id`，再通过 `GET /v1/videos/{task_id}` 查询。视频创建可能产生费用，网络结果不确定时不要自动重发 POST。
