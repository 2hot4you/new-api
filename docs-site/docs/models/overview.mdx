# 模型概览

当前检入的 Development 公开目录快照包含 **10 个 Provider** 和 **37 个模型**。本页提供稳定入口与协议索引；每个模型的完整能力、参数和调用示例由同一快照生成在 [Provider 与模型目录](/providers)中，避免在多个手写页面复制 37 行容易漂移的清单。

## 快照来源

目录来自公开 Development 定价端点 [https://dev.molii.co/api/pricing](https://dev.molii.co/api/pricing)，当前快照版本为 `a42d372ccf0b5dd13ecf71203521f9d2`。同步是显式维护操作；日常测试、开发和构建只读取检入快照，不依赖 Development 网络可用性。

快照表示文档生成时的公开目录，不替代账户授权判断。调用前使用[模型 API](/api-reference/models)读取当前 API Key 实际可用的模型；价格与权限以平台模型广场和账户当前状态为准。

## 兼容协议索引

| 快照端点类型 | API 参考 | 公开端点 |
| --- | --- | --- |
| `openai` | [Chat Completions](/api-reference/chat-completions) | `POST /v1/chat/completions` |
| `openai-response` | [Responses](/api-reference/responses) | `POST /v1/responses` |
| `anthropic` | [Anthropic Messages](/api-reference/anthropic-messages) | `POST /v1/messages` |
| `gemini` | [Gemini GenerateContent](/api-reference/gemini-generate-content) | `POST /v1beta/models/{model}:generateContent` |
| `image-generation` | [图片 API](/api-reference/images) | `POST /v1/images/generations`、`POST /v1/images/edits` |
| `openai-video` | [视频 API](/api-reference/videos) | `POST /v1/videos` 与任务查询、下载 GET |

不同兼容协议使用不同请求头。OpenAI 兼容端点使用 Bearer；Anthropic 与 Gemini 的请求头以各自参考页为准。示例只使用环境变量，不要把 API Key 放入客户端代码、URL 或日志。
