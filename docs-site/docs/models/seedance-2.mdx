# Seedance

创建端点为 `POST /v1/videos`。兼容路径 `POST /v1/video/generations` 使用相同的 Seedance 请求字段；本页和示例统一使用 `/v1/videos`，便于在同一路径下查询任务与下载结果。

## 模型与分辨率

| 版本 | 模型 ID | 分辨率 |
| --- | --- | --- |
| 标准版 | `doubao-seedance-2-0-260128` | `480p`、`720p`、`1080p`、`4k` |
| Fast | `doubao-seedance-2-0-fast-260128` | `480p`、`720p` |
| Mini | `doubao-seedance-2-0-mini-260615` | `480p`、`720p` |
| 2.5（最长 `30` 秒） | `doubao-seedance-2-5-260628` | `480p`、`720p`、`1080p` |

Fast/Mini 不支持 `1080p` 和 `4k`；2.5 不支持 `4k`。这些组合会在创建阶段被拒绝。

## 请求参数

<ParameterTable rows={seedanceParameters} />

`ratio` 的完整可选值是 `adaptive`、`16:9`、`4:3`、`1:1`、`3:4`、`9:16` 和 `21:9`。

`duration` 必须是 `-1`，或所选模型范围内的整数：标准/Fast/Mini 为 `4`–`15`，2.5 为 `4`–`30`。默认值是 `5`。

`tools` 目前只支持以下一项；任何其他 `type` 都会被拒绝：

```json
[{ "type": "web_search" }]
```

显式传入 `generate_audio: false` 或 `watermark: false` 会保留该值。不要依赖省略与 `false` 表达相同业务意图；需要关闭能力时请显式传值。

## 最小请求

```json
{
  "model": "doubao-seedance-2-0-260128",
  "content": [
    {
      "type": "text",
      "text": "清晨的海边木栈道，镜头平稳向前移动"
    }
  ],
  "resolution": "720p",
  "ratio": "16:9",
  "duration": 5,
  "generate_audio": true,
  "watermark": false
}
```

也可以只传非空 `prompt`，平台会把它追加为一个 `text` 输入。如果同时传 `prompt` 与 `content` 中的 `text`，两者都会进入请求；通常只选择一种方式，避免重复提示词。

## 响应与任务状态

创建成功会返回公开任务 ID：

```json
{
  "id": "task_example_123",
  "task_id": "task_example_123",
  "object": "video",
  "model": "doubao-seedance-2-0-260128",
  "status": "queued",
  "progress": 0,
  "created_at": 1786300000
}
```

用 `GET /v1/videos/{task_id}` 查询，状态为 `queued`、`in_progress`、`completed` 或 `failed`。完成后响应会提供经过严格校验的火山 TOS 签名视频 URL；签名会过期，请及时使用。请遵守[异步任务](../api-basics/async-tasks)中的退避、总超时和“不自动重试付费 POST”规则。

多模态输入的角色和互斥规则较严格，请在提交前阅读[多模态输入指南](../guides/seedance-multimodal)。
