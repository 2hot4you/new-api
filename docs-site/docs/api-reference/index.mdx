# API 参考

本参考只包含使用 API Key 调用的公开接口。所有示例都使用环境变量，并按兼容协议说明鉴权、请求、响应和安全重试边界。

## 开始前确认

先按 [Base URL](/api-basics/base-url) 选择可信环境地址，再阅读[身份验证](/api-basics/authentication)。OpenAI 兼容端点使用 `Authorization: Bearer`；Anthropic Messages 和 Gemini GenerateContent 使用各自参考页列出的请求头。API Key 只能保存在服务端或本机安全环境。付费创建请求不要配置自动重试。

## 选择端点

- [Chat Completions](/api-reference/chat-completions)：`POST /v1/chat/completions`，OpenAI 消息格式。
- [Responses](/api-reference/responses)：`POST /v1/responses`，OpenAI Responses 格式。
- [Anthropic Messages](/api-reference/anthropic-messages)：`POST /v1/messages`，Anthropic 消息格式。
- [Gemini GenerateContent](/api-reference/gemini-generate-content)：`POST /v1beta/models/{model}:generateContent`，Gemini 原生格式。

具体模型支持哪些协议，以 [Provider 与模型](/providers)中的模型页为准。

### 模型、媒体与资源

- [模型](/api-reference/models)：读取当前 API Key 可用的模型。
- [图片](/api-reference/images)：图片生成与编辑。
- [视频](/api-reference/videos)：视频创建、编辑、查询和下载。
- [文件](/api-reference/files)：上传和管理请求使用的用户媒体文件。
- [Seedance](/api-reference/seedance)：Seedance 多模态视频创建与查询。
- [临时素材](/api-reference/assets)：创建、查询和删除临时素材。
- [错误](/api-reference/errors)：标准错误、状态码和公开 Request ID。

## 同步与异步响应

图片请求通常直接返回结果；视频请求通常先返回任务 ID，再通过查询接口获得状态、媒体和最终计费。轮询规则见[异步任务](/api-basics/async-tasks)。

## 计费与用量字段

提交时的预估用于展示和额度检查，任务完成后的实际 Token 与最终结算才是权威结果。详见[计费与用量](/api-basics/billing-and-usage)。

## 错误与 Request ID

失败时保存公开 Request ID，并按状态码和操作类型决定是否重试。不要在日志或工单中记录完整 Authorization。详见[错误与重试](/api-basics/errors-retries)。

## 响应兼容性

客户端应读取各参考页列出的稳定字段，并忽略响应中不认识的附加字段。不要依赖未公开的实现细节或供应商原始错误。
