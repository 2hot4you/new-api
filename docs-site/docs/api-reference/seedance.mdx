# Seedance API

Seedance 支持纯文本、首尾帧、参考图片、参考视频和参考音频组合生成。新接入统一使用 `POST /v1/videos` 创建任务，再通过同一组路径查询和下载结果。

兼容路径 `POST /v1/video/generations` 和 `GET /v1/video/generations/{task_id}` 继续可用，但属于旧版兼容入口；新客户端不应依赖其响应结构。

## 模型与边界

| 模型 ID | 定位 | 分辨率 | 时长 |
| --- | --- | --- | --- |
| `doubao-seedance-2-0-260128` | 标准版 | `480p`、`720p`、`1080p`、`4k` | `4`–`15` 秒 |
| `doubao-seedance-2-0-fast-260128` | Fast 版 | `480p`、`720p` | `4`–`15` 秒 |
| `doubao-seedance-2-0-mini-260615` | Mini 版 | `480p`、`720p` | `4`–`15` 秒 |
| `doubao-seedance-2-5-260628` | 2.5 版 | `480p`、`720p`、`1080p` | `4`–`30` 秒 |

四个模型都接受文本、图片、视频和音频参考。具体输出能力以模型页展示为准；不支持的分辨率或时长会在创建阶段被拒绝。

## 创建视频

```http
POST /v1/videos
Authorization: Bearer $MOLII_API_KEY
Content-Type: application/json
```

### 顶层参数

| 参数 | 类型 | 必填 | 默认值 | 可选值/范围 | 说明 |
| --- | --- | --- | --- | --- | --- |
| `model` | string | 是 | 无 | 上表中的模型 ID | 生成模型 |
| `content` | object[] | 条件必填 | `[]` | 见下文 | 有顺序的文本和媒体输入 |
| `prompt` | string | 条件必填 | 无 | 非空字符串 | 纯文本便捷字段 |
| `generate_audio` | boolean | 否 | `true` | `true`、`false` | 是否请求生成同步音频 |
| `resolution` | string | 否 | `720p` | `480p`、`720p`、`1080p`、`4k` | 必须符合所选模型边界 |
| `ratio` | string | 否 | `adaptive` | `16:9`、`4:3`、`1:1`、`3:4`、`9:16`、`21:9`、`adaptive` | 输出比例 |
| `duration` | integer | 否 | `5` | 模型范围内整数或 `-1` | `-1` 表示智能时长 |
| `watermark` | boolean | 否 | `false` | `true`、`false` | 是否请求添加水印 |
| `tools` | object[] | 否 | `[]` | 当前仅 `[{"type":"web_search"}]` | 可用工具 |

`content` 与 `prompt` 至少提供一种有效输入。若同时提供 `prompt` 和 `content` 中的 `text`，两段文字都会进入请求，通常不建议重复。

### Content 多模态项

| `type` | 载荷字段 | `role` | 数量与约束 |
| --- | --- | --- | --- |
| `text` | `text` | 无 | 非空文本 |
| `image_url` | `image_url.url` | `first_frame`、`last_frame`、`reference_image` | 图片总数最多 9 张 |
| `video_url` | `video_url.url` | `reference_video` | 最多 3 个；单个 2–15 秒，所有参考视频总时长不超过 15 秒 |
| `audio_url` | `audio_url.url` | `reference_audio` | 最多 3 条；单条 2–15 秒，所有参考音频总时长不超过 15 秒；不能脱离图片或视频单独使用 |

帧模式必须有一个 `first_frame`，可以再提供一个 `last_frame`；帧模式不能与 `reference_image`、`reference_video` 或 `reference_audio` 混用。多模态参考图片必须明确使用 `reference_image`。

媒体地址可使用公网 URL；图片和音频还可使用受支持的 Data URL。图片、视频和音频都可使用当前账户创建的 `asset://` 临时素材 URI。

## 创建请求示例

以下示例共用环境变量：

```bash
export MOLII_API_BASE_URL="https://your-molii-host.example"
export MOLII_API_KEY="replace-with-your-key"
```

### 纯文本生成

```bash
curl --fail-with-body --silent --show-error \
  --request POST \
  --url "${MOLII_API_BASE_URL%/}/v1/videos" \
  --header "Authorization: Bearer $MOLII_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{
    "model": "doubao-seedance-2-0-260128",
    "content": [{"type": "text", "text": "清晨的海边木栈道，镜头平稳向前移动，环境声音自然同步"}],
    "generate_audio": true,
    "resolution": "720p",
    "ratio": "16:9",
    "duration": 5,
    "watermark": false
  }'
```

### 首帧图生视频

```json
{
  "model": "doubao-seedance-2-0-fast-260128",
  "content": [
    {"type": "text", "text": "镜头缓慢拉远，云层从山谷中流过"},
    {
      "type": "image_url",
      "image_url": {"url": "https://cdn.example.com/first-frame.jpg"},
      "role": "first_frame"
    }
  ],
  "resolution": "720p",
  "ratio": "adaptive",
  "duration": 6,
  "generate_audio": true,
  "watermark": false
}
```

### 首尾帧生视频

### 创建成功响应

```json
{
  "id": "task_public_789",
  "task_id": "task_public_789",
  "object": "video",
  "model": "doubao-seedance-2-5-260628",
  "status": "queued",
  "progress": 0,
  "created_at": 1788192000
}
```

保存 `id`。创建 POST 可能产生费用，网络超时不代表服务端未受理，不要自动重复提交。

## 查询任务

```http
GET /v1/videos/{task_id}
Authorization: Bearer $MOLII_API_KEY
```

```bash
TASK_ID="task_public_789"

curl --fail-with-body --silent --show-error \
  --url "${MOLII_API_BASE_URL%/}/v1/videos/${TASK_ID}" \
  --header "Authorization: Bearer $MOLII_API_KEY" \
  --header "Accept: application/json"
```

| `status` | 含义 | 是否继续轮询 |
| --- | --- | --- |
| `queued` | 已受理或排队中 | 是 |
| `in_progress` | 正在生成 | 是 |
| `completed` | 成功终态 | 否 |
| `failed` | 失败终态 | 否 |

处理中响应：

```json
{
  "id": "task_public_789",
  "task_id": "task_public_789",
  "object": "video",
  "model": "doubao-seedance-2-5-260628",
  "status": "in_progress",
  "progress": 42,
  "created_at": 1788192000
}
```

成功响应：

```json
{
  "id": "task_public_789",
  "task_id": "task_public_789",
  "object": "video",
  "model": "doubao-seedance-2-5-260628",
  "status": "completed",
  "progress": 100,
  "created_at": 1788192000,
  "completed_at": 1788192068,
  "usage": {
    "completion_tokens": 432000,
    "total_tokens": 432000,
    "tool_usage": {"web_search": 0}
  },
  "metadata": {
    "url": "https://signed-media.example.com/result.mp4?signature=temporary"
  }
}
```

失败响应：

```json
{
  "id": "task_public_789",
  "task_id": "task_public_789",
  "object": "video",
  "model": "doubao-seedance-2-5-260628",
  "status": "failed",
  "progress": 100,
  "error": {
    "code": "video_task_failed",
    "message": "Video generation task failed"
  }
}
```

轮询 GET 可对传输错误、`429` 和暂时性 `5xx` 退避重试，但必须设置总截止时间。完整的有界轮询实现见 [curl 示例](/examples/seedance-curl)。

## 获取与下载结果

`metadata.url` 是短期签名地址，不应当作永久资源 URL。推荐通过 Molii 内容端点获取结果：

```http
GET /v1/videos/{task_id}/content
```

```bash
curl --fail-with-body --silent --show-error \
  --max-redirs 0 \
  --url "${MOLII_API_BASE_URL%/}/v1/videos/${TASK_ID}/content?download=1" \
  --header "Authorization: Bearer $MOLII_API_KEY" \
  --header "Accept: video/*" \
  --output seedance-result.mp4
```

不要在携带 API Key 时自动跟随跨主机重定向。下载后应验证 HTTP 状态和 `Content-Type: video/*`。

## 临时素材

临时素材把公网图片、视频或音频转换成当前账户可引用的 `asset://` URI。素材有过期时间，不是永久文件存储。

创建素材：

```http
POST /v1/assets
```

```bash
curl --fail-with-body --silent --show-error \
  --request POST \
  --url "${MOLII_API_BASE_URL%/}/v1/assets" \
  --header "Authorization: Bearer $MOLII_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{
    "url": "https://cdn.example.com/reference.mp4",
    "asset_type": "video",
    "name": "reference-video-01"
  }'
```

```json
{"id": "asset-molii-example123"}
```

查询并等待素材就绪：

```http
GET /v1/assets/{id}
```

```json
{
  "id": "asset-molii-example123",
  "asset_type": "video",
  "name": "reference-video-01",
  "status": "SUCCESS",
  "created_at": 1788192000,
  "expires_at": 1788278400
}
```

引用素材：

```json
{
  "type": "video_url",
  "video_url": {"url": "asset://asset-molii-example123"},
  "role": "reference_video"
}
```

删除素材：

```http
DELETE /v1/assets/{id}
```

只有成功状态且未过期的素材可用于新任务。公共素材 ID 与创建它的用户绑定，不要跨账户共享或自行构造。完整状态、URL 安全规则和错误码见[临时素材 API](/api-reference/assets)与[生命周期指南](/guides/temporary-assets)。

## 错误与安全重试

- `400 invalid_request`：内容组合、role、比例、模型能力或工具不合法。
- `400 invalid_seconds`：时长不在所选模型边界内，且不是 `-1`。
- `400 temporary_asset_not_ready`：临时素材仍在处理。
- `400 temporary_asset_expired`：临时素材已过期。
- `401`/`403`：修复鉴权、模型权限或账户归属问题。
- `404`：任务或素材不存在，或不属于当前用户。
- `429`、暂时性 `5xx`：仅查询 GET 可在截止时间内退避重试。

上线前请同时阅读[异步任务](/api-basics/async-tasks)、[错误与重试](/api-basics/errors-retries)和[多模态输入指南](/guides/seedance-multimodal)。

## `POST /v1/video/generations`

Seedance 创建任务的旧版兼容入口。它接受与 `POST /v1/videos` 相同的多模态请求体；新接入应优先使用 `/v1/videos`。

### 鉴权

使用 `Authorization: Bearer $MOLII_API_KEY`。密钥只应保存在服务端安全配置中。

### 请求参数

请求体字段、默认值、模型边界和 `content` 规则与本页“创建视频”章节完全相同。`model` 必填，`content` 与 `prompt` 至少提供一种有效输入。

### 请求示例

```bash
curl --fail-with-body --silent --show-error \
  --request POST \
  --url "${MOLII_API_BASE_URL%/}/v1/video/generations" \
  --header "Authorization: Bearer $MOLII_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{
    "model": "doubao-seedance-2-0-260128",
    "content": [{"type": "text", "text": "晨雾中的竹林，镜头缓慢向前移动"}],
    "resolution": "720p",
    "ratio": "16:9",
    "duration": 5,
    "generate_audio": true,
    "watermark": false
  }'
```

### 成功响应

```json
{
  "id": "task_public_789",
  "task_id": "task_public_789",
  "object": "video",
  "model": "doubao-seedance-2-0-260128",
  "status": "queued",
  "progress": 0
}
```

保存公共任务 ID。客户端不得构造或记录供应商任务标识。

### 错误与重试

字段组合错误返回 `400`，鉴权或权限问题返回 `401`/`403`，限流返回 `429`。该 POST 不承诺幂等；网络结果不确定时不要自动重放。

### 计费

兼容入口与推荐入口使用相同的预扣和终态结算规则，不会因为路径不同产生第二套价格。查询响应中的 `usage` 是模型用量。

## `GET /v1/video/generations/{task_id}`

查询 Seedance 任务的旧版兼容视图。新客户端建议使用 `GET /v1/videos/{task_id}` 获取统一的小写状态结构。

### 鉴权

使用 `Authorization: Bearer $MOLII_API_KEY`，且任务必须属于当前用户。

### 请求参数

| 参数 | 位置 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| `task_id` | path | string | 是 | 创建响应返回的公共任务 ID |

该接口没有请求体。

### 请求示例

```bash
curl --fail-with-body --silent --show-error \
  --url "${MOLII_API_BASE_URL%/}/v1/video/generations/task_public_789" \
  --header "Authorization: Bearer $MOLII_API_KEY" \
  --header "Accept: application/json"
```

### 成功响应

```json
{
  "code": "success",
  "message": "",
  "data": {
    "task_id": "task_public_789",
    "status": "IN_PROGRESS",
    "progress": "42%",
    "fail_reason": "",
    "result_url": ""
  }
}
```

兼容状态为 `SUBMITTED`、`QUEUED`、`IN_PROGRESS`、`SUCCESS` 或 `FAILURE`。只有 `SUCCESS` 与 `FAILURE` 是终态。

### 错误与重试

`404` 表示任务不存在或不属于当前用户。传输错误、`429` 和暂时性 `5xx` 可在总截止时间内退避重试；其他 `4xx` 应先修复请求。

### 计费

查询不产生第二次生成费用。最终用量与结算以任务终态数据和平台账单为准；客户端不应根据缺失字段自行猜价。
