# 错误与重试

标准错误响应包含稳定的 `code` 和可展示的 `message`：

```json
{
  "error": {
    "code": "invalid_request",
    "message": "请检查必填字段和取值范围"
  }
}
```

兼容任务查询还可能使用 `{ "code": "…", "message": "…", "data": … }` 包裹。程序应根据 HTTP 状态和公开错误码分支，不要解析自然语言消息来控制流程。

## 处理矩阵

| HTTP 状态 | 常见原因 | 动作 |
| --- | --- | --- |
| 400 | 参数、模型或媒体输入无效 | 修正请求，不重试 |
| 401 | API Key 缺失或无效 | 修复密钥，不重试 |
| 403 | 当前密钥无权访问 | 修复权限，不重试 |
| 404 | 任务或素材不存在 | 核对 ID 和所属密钥 |
| 429 | 请求过快 | GET 按 `Retry-After` 或退避重试 |
| 5xx / 502 | 服务暂时不可用 | GET 可有界退避；POST 先确认结果 |

## 重试边界

付费 POST 禁止自动重试，包括图像生成、图像编辑、视频创建、视频编辑和素材创建。超时或连接断开无法证明服务端未受理；自动重发可能导致重复任务和额外计费。

安全 GET 可以对 429 和暂时性 5xx 使用指数退避（exponential backoff）：

```ts
function retryDelay(attempt: number, retryAfter: string | null, now = Date.now()): number {
  const capped = Math.min(2 ** attempt, 30) * 1000;
  const fallback = capped + Math.random() * 500; // jitter
  if (retryAfter === null) return fallback;

  const trimmed = retryAfter.trim();
  if (/^\d+$/.test(trimmed)) {
    const seconds = Number(trimmed);
    if (Number.isSafeInteger(seconds) && seconds <= Number.MAX_SAFE_INTEGER / 1000) {
      return seconds * 1000;
    }
    return fallback;
  }

  const retryAt = Date.parse(trimmed);
  if (!Number.isFinite(retryAt)) return fallback;
  const delta = retryAt - now;
  return delta >= 0 ? delta : fallback;
}
```

始终设置最大尝试次数或总截止时间。`Retry-After` 只接受非负整数 delta-seconds 或合法且不早于当前时间的 HTTP-date；空值、负数、非法值和溢出值都安全回退到带抖动（jitter）的退避，避免多个客户端同时重试。

## 记录公开 Request ID

每个响应的 `X-Oneapi-Request-Id` 是 Molii 本次请求的公开排障标识。发生错误时，可以将它与 HTTP 状态、公开错误码一起提供给支持人员排障。它不是上游请求标识，也不应替代你的业务关联 ID。

日志前应对该值脱敏：只保留 ASCII 字母、数字、`.`、`_`、`:` 和 `-`，并限制到 128 个字符，防止伪造日志行。不要记录整组响应头、`Authorization` 或带签名的媒体 URL。

### curl

```bash
set -e
headers_file="$(mktemp)"
body_file="$(mktemp)"
trap 'rm -f "$headers_file" "$body_file"' EXIT

if http_code="$(curl --silent --show-error \
  --connect-timeout 10 \
  --max-time 30 \
  --url "${MOLII_API_BASE_URL%/}/v1/models" \
  --header "Authorization: Bearer $MOLII_API_KEY" \
  --dump-header "$headers_file" \
  --output "$body_file" \
  --write-out '%{http_code}')"; then
  curl_exit=0
else
  curl_exit=$?
fi
request_id="$(awk 'tolower($1) == "x-oneapi-request-id:" { value=$2 } END { gsub(/\r/, "", value); print value }' "$headers_file")"
safe_request_id="$(printf '%s' "$request_id" | LC_ALL=C tr -cd 'A-Za-z0-9._:-' | cut -c1-128)"
[ -z "$safe_request_id" ] || printf 'request_id=%s\n' "$safe_request_id"
[ "$curl_exit" -eq 0 ] || { printf 'curl failed with exit %s\n' "$curl_exit" >&2; exit 1; }
case "$http_code" in
  2??) cat "$body_file" ;;
  *) printf 'HTTP %s request_id=%s\n' "$http_code" "${safe_request_id:-missing}" >&2; exit 1 ;;
esac
```

### Python

```python
import os
import requests

response = requests.get(
    f"{os.environ['MOLII_API_BASE_URL'].rstrip('/')}/v1/models",
    headers={"Authorization": f"Bearer {os.environ['MOLII_API_KEY']}"},
    timeout=(10, 30),
)
request_id = response.headers.get("X-Oneapi-Request-Id", "")
safe_request_id = "".join(c for c in request_id if c.isascii() and (c.isalnum() or c in "._:-"))[:128]
if safe_request_id:
    print(f"request_id={safe_request_id}")
try:
    response.raise_for_status()
except requests.HTTPError as error:
    raise RuntimeError(
        f"HTTP {response.status_code}; request_id={safe_request_id or 'missing'}"
    ) from error
```

### TypeScript

```ts
const response = await fetch(`${baseUrl}/v1/models`, {
  headers: { Authorization: `Bearer ${apiKey}` },
  signal: AbortSignal.timeout(30_000),
});
const requestId = response.headers.get('X-Oneapi-Request-Id') ?? '';
const safeRequestId = requestId.replace(/[^A-Za-z0-9._:-]/g, '').slice(0, 128);
if (safeRequestId) console.info('request_id=%s', safeRequestId);
if (!response.ok) {
  throw new Error(`HTTP ${response.status}; request_id=${safeRequestId || 'missing'}`);
}
```

## 付费 POST 超时时

- 如果已经拿到任务 ID，保存它并只用 GET 查询。
- 如果没有拿到任务 ID，不要立即重复提交；记录本地请求时间和不含密钥的关联信息，再联系支持确认。
- 只有在明确确认前一次请求未创建任务后，才由用户或业务流程决定是否重新提交。

日志可以记录 HTTP 状态、公开错误码和任务 ID，但必须删除 `Authorization` 请求头、完整媒体签名 URL及其他敏感内容。
